## 결정 (2026-11-02 사용자)

| 요청 | 결정 |
|---|---|
| PLC 연동 | 실제 PLC 장비 · 시험환경을 제공할 수 없어 **시험범위에서 제외** — 다른 제외 기능처럼 라이선스 확장 옵션(`plc`)으로 프로그램에서 숨기고 매뉴얼 · 제품설명서에서 삭제 |
| 롤러 검사 (라인스캔) | 반입 카메라(Basler 에어리어)로 시험할 수 없어 **같이 제외** (확장 옵션 `line-scan`) |
| 버전 | 프로그램을 고쳐야 하므로 **BODA VMS v1.48.1** 로 다시 확정해 알린다 |
| 운영체제 | Windows 11 (x64) 로 통일. 시험 PC(실증 PC) OS 는 사용자가 확인 — Windows 10 이면 11 로 올려야 함(TTA 사전 체크리스트 양식: EOL OS 사용 불가) |
| 제품설명서 | v1.1 — 작성일 · 문서 이력 · 신청 기업 · 작성자/연락처 기입 |

구자경 수석님, 안녕하세요.

확인 요청하신 사항을 아래와 같이 회신드립니다.

**1. PLC 연동 기능**

- 실제 PLC 장비와 시험환경을 제공하기 어려워 PLC 연동 기능은 시험범위에서 제외합니다.
- 다른 제외 기능과 같이 시험 제출 구성에서 PLC 통신 설정과 관련 메뉴가 나타나지 않도록 프로그램을 정리했고, 사용자 매뉴얼과 제품설명서에서도 삭제했습니다.
- 설비 신호 연동(트리거 입력 · 판정 출력)은 디지털 IO 보드(ADLink PCI-7432) 실물로 시험합니다.
- 같은 이유로 라인스캔 카메라 전용 롤러 검사(Roller Inspection) 기능도 시험범위에서 제외하고 같은 방식으로 정리했습니다.

**2. 최종 버전**

- 위 정리를 프로그램에 반영하여 최종 시험 대상 버전을 **BODA VMS v1.48.1** 로 확정합니다 (판매용 정식 버전, 2026년 11월 [확인 필요]일 공개).
- 설치 프로그램, 프로그램 내 버전 정보, 사용자 매뉴얼, 제품설명서를 모두 BODA VMS v1.48.1 로 맞췄으며, 시험 종료까지 다른 버전은 배포하지 않습니다.

**3. 운영체제**

- 시험대상 운영체제는 Windows 11 (x64) 이며, 사용자 매뉴얼과 제품설명서의 표기를 Windows 11 (x64) 로 통일했습니다.

**4. 제품설명서**

- 작성일, 문서 이력, 신청 기업, 작성자 및 연락처를 기입하여 제품설명서 v1.1 로 갱신했습니다.

수정한 사용자 매뉴얼(v3.1), 제품설명서(v1.1), 사전 체크리스트를 첨부드립니다. 위 내용을 기준으로 시험범위 및 견적 검토를 부탁드립니다.
