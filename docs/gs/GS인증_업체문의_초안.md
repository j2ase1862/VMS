# GS 인증 시험 문의 메일 초안

> 발송 전 확인: 수신처(인증 업체 담당자), 회사명·연락처 서명, 첨부(사전 체크리스트 작성본).

제목: GS 인증 시험 사전 문의 — 머신 비전 검사 솔루션 (BODA VMS)

안녕하세요, [회사명]의 [담당자명]입니다.

당사 머신 비전 검사 솔루션 "BODA VMS"의 GS 인증(시험 목적: 조달 등록)을
준비하고 있어, 견적·일정 협의에 앞서 몇 가지 문의드립니다.
사전 체크리스트는 작성 중이며, 아래 문의 답변에 따라 시험 범위(기능 리스트)가
달라지는 항목이 있어 함께 확인 후 제출하겠습니다.

## 제품 개요 (문의 이해를 위한 요약)

- Windows 데스크톱 단독 설치형(MSI) 산업용 비전 검사 솔루션 + 같은 MSI 에
  동봉되는 로컬 웹 서버(생산 이력·작업지시 관리, Chrome 브라우저 사용)
- 산업용 카메라(GigE 2D)로 부품을 촬영해 패턴 매칭·치수 측정·불량 판정을
  수행하며, 일부 기능은 3D 카메라·PLC/IO 보드 등 외부 장비와 연동됩니다
- 서버 별도 구축 없음 (단일 PC 구성, DB 는 내장 SQLite)

## 문의 사항

### 1. 하드웨어(장비) 준비 범위
비전 검사 제품 특성상 카메라 입력이 필요합니다.
- 2D 산업용 카메라(GigE)·렌즈·조명·실물 샘플 부품은 당사가 준비/반입
  가능합니다. **시험기관 시험실에 당사가 장비를 반입·설치해 시험하는 방식이
  일반적인지**, 아니면 장비 사유의 현장시험으로 진행해야 하는지 문의드립니다.
- **3D 카메라는 시험 기간 확보가 어렵습니다.** 3D 카메라 의존 기능(3D 점군
  측정·3D 정렬)은
  (a) 저장된 3D 데이터 파일을 불러오는 방식(제품 내장 기능)으로 대체 시험이
  인정되는지,
  (b) 인정되지 않는다면 해당 기능을 시험 범위(기능 리스트)에서 제외하고
  진행할 수 있는지 — 제외 시 매뉴얼 기재 범위도 맞춰야 하는지 문의드립니다.
- PLC·IO 보드·로봇 연동 기능도 동일하게 시뮬레이션 대체 또는 범위 제외가
  가능한지 문의드립니다.

### 2. 시험용 데이터 (샘플 이미지)
- 검사 기능(패턴 매칭·치수 측정·불량 판정) 시험을 위한 샘플 이미지는 당사가
  제공하는 것으로 이해하고 있습니다. **룰 기반 검사 제품의 경우 기능별
  정상/불량 이미지를 어느 정도 수량으로 준비하면 되는지**, 정답(어노테이션)
  형식 요구가 있는지 가이드 부탁드립니다.
- 실물 부품 + 카메라 라이브 촬영으로 시연 가능한 기능은 이미지 파일 없이
  실물 시연으로 갈음되는지도 확인 부탁드립니다.

### 3. AI(딥러닝) 기능의 범위 처리
- 제품에 딥러닝 추론 기능(객체 분할·이상 탐지·분류, 학습된 모델 파일을 불러와
  추론만 수행하며 **제품 내 학습/재학습 기능은 없음**)이 포함되어 있습니다.
- 이 경우에도 'AI 기능 포함'으로 분류되어 학습데이터·정답셋 제출 요건과
  기간·수수료가 달라지는지, 요구되는 데이터 수준(수량·라벨 형식)은 어느
  정도인지 문의드립니다.
- 부담이 큰 경우 딥러닝 툴만 시험 범위에서 제외하는 것이 가능한지도 함께
  문의드립니다.

### 4. 데스크톱 + 동봉 웹 복합 구성
- 데스크톱 앱과 동봉 웹 서버(동일 PC 설치, 브라우저는 Chrome 1종 기준)를
  하나의 제품으로 인증받으려 합니다. 복합 구성에 따른 기간·수수료 영향과,
  브라우저를 Chrome 1종으로 한정해 진행 가능한지 확인 부탁드립니다.

### 5. 제품 업데이트 기능
- 제품에 인앱 업데이트(온라인 배포 저장소에서 새 버전 확인·다운로드·설치)
  기능이 있습니다. 이 기능을 인증 범위에 포함할 경우 "업데이트 서버·무결성
  확인 환경"으로 어떤 준비가 필요한지(현재 GitHub Releases 기반), 또는 범위
  제외 시 유의점이 있는지 문의드립니다.

### 6. 일정
- 조달 등록 일정상 **10월 말까지 인증 획득**을 목표하고 있습니다. 9월 중
  시험 착수 시 성적서·인증서 발급까지 통상 소요 기간과, 시험 중 결함 발견 시
  수정본 재제출·재시험 절차(라운드 수·추가 기간)를 안내 부탁드립니다.

### 7. 시험 환경 사전 정보
- 당사 제품은 PC 하드웨어에 바인딩되는 라이선스 체계를 사용합니다. 시험용
  라이선스 발급을 위해 **시험 PC 정보를 사전에 받을 수 있는지**, 또는 당사가
  시험용 PC(라이선스 적용·GPU 포함)를 지참하는 방식이 가능한지 문의드립니다.
- 시험 PC 최소 사양 참고: Windows 11, AVX2 지원 CPU, (딥러닝 기능 포함 시)
  GPU 권장.

### 8. 제출 문서
- 관리자/사용자 매뉴얼 외에 제품설명서(카탈로그)가 필요한 것으로 확인했습니다.
  각 문서의 양식·분량 제약이 있는지, 매뉴얼은 PDF 단일 파일로 충분한지 확인
  부탁드립니다.

### 9. KOLAS 성적서
- 시험 목적이 조달 등록인데, 당사가 진행하려는 등록 경로에서 KOLAS 성적서가
  요구되는 경우가 있는지(있다면 신청 시점에 함께 선택해야 하는지) 확인
  부탁드립니다.

답변 주시면 사전 체크리스트와 기능 리스트를 확정해 회신드리겠습니다.
