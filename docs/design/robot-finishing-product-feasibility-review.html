로봇 샌딩·그라인딩 솔루션 자체 개발 타당성 검토

v0.2 (특허 1차 조사 반영) · 2026-08-04 · 연구소 · 내부 검토용
요약: MARI(캐나다) AARS 도입 대안으로서의 자체 개발은 기술적으로 가능하다 — 핵심 파이프라인(스캔→커버리지 경로→공구 포즈)은 WeldTeach M1~M6 로 이미 구현·정량 검증돼 있다. 두산 협동로봇 제한 + 자동 분할·노코드 UI 스코핑은 타당하며, 최대 리스크는 기술이 아니라 공정 지식 축적 시간과 특허(FTO)다. MARI 의 한국 특허 출원이 존재하나(미등록·심사 중) 청구 방식이 당사 방식과 달라 예비 판단으로는 회피 가능성이 높다 (부록 A).

1. 검토 배경과 목적

MARI(Maple Advanced Robotics Inc., 캐나다)의 CAD-free 로봇 샌딩·그라인딩 솔루션 AARS 도입을 검토하였으나 단가가 높아, 연구소 자체 개발 타당성을 검토한다. 검토 시나리오는 판매용 범용 제품 + 두산 협동로봇 제한 + 자동 곡면 분할·결함 기반 적응 가공(④)과 노코드 플로차트 UI(⑤) 구현이다.

4. 검토 시나리오 평가

4.1 두산 협동로봇 제한 → 격차 ①·② 대부분 소멸

격차두산 제한 후
① 로봇 연동포스트프로세서 = JSON→DRL 변환기 하나. 공식 SDK·ROS2·DART 시뮬레이터 존재
② 힘 제어M 시리즈 전 관절 토크센서 내장 — task_compliance_ctrl / set_desired_force API. 당사 "힘 제어는 로봇단 책임" 설계와 정합. 고품질 요구 시 액티브 이펙터 추가 구매
판로두산로보틱스 국내사 — 솔루션 파트너 생태계 등재 시 영업 채널
트레이드오프: 협동로봇 강성·속도 한계로 중(重)연삭·대형 스톡 제거는 제외 — 타깃은 목공 샌딩·용접비드 경연삭·폴리싱·소형 금속 피니싱 (국내 HMLV 중소 제조와 정합 = 집중).

4.2 격차 ④ — 3단계 분해

층내용난이도재료
Lv1 자동 곡면 분할법선·곡률 리전 그로잉 + RANSAC. 라쏘를 "분할 결과 승인/수정" UX 로 진화중M1 법선·KdTree 재사용
Lv2 결함→영역 자동결함 마스크 → 점군 영역 → 커버리지 배관 연결중DL·포토메트릭 자산 = 차별화 강점
Lv3 파라미터 적응재료·공구·힘·이송속도별 제거율 공정 지식 (MARI "physics-informed AI" 의 실체)대 — 데이터 축적M5 영역별 파라미터가 그릇. 프리셋 출시 → 현장 데이터로 고도화

4.3 격차 ⑤ 노코드 UI · 4.4 제외한 ③의 최소치

⑤: VisionSetup 이 이미 도구 드래그·연결·실행 파이프라인 워크스페이스 — 중소 규모, 리스크 낮음.

③: 풀 모션 플래닝 생략은 협동로봇 안전정지로 감수 가능하나, IK 도달성·관절 한계·특이점 검사는 생략 불가 — 없으면 내보낸 경로가 로봇에서 실패해 제품 신뢰를 잃는다. 두산 기구학 공개 + DART 시뮬레이터로 최소치 구현 (풀 플래닝 대비 소규모).

5. 단계별 로드맵 (안)

기간은 소수 인원 + AI 보조 개발 전제의 개략 추정 — P0 결과로 재산정한다.
단계내용산출물 / 판정개략 기간
P0 실기 실증두산 M 1대 + JSON→DRL 스텁 + 내장 힘제어 시편 샌딩실기 데모 영상(투자 설득·초기 영업 자료), 공정 성립 판정1~2개월 (로봇 확보 후)
P1IK 도달성 검사 + Lv1 자동 분할분할 정량 검증, 경로 실기 성공률2~3개월
P2노코드 플로차트 UI비개발자 셋업 시연 (AARS "10분" 대응)2~3개월
P3Lv2 결함→영역 자동화결함 1~2종 자동 가공 데모2~3개월
P4Lv3 공정 프리셋 + 현장 파일럿Ra 개선 정량, 파일럿 피드백지속

필요 장비 (견적 필요): 두산 M 시리즈 1대(M1013급), 스핀들/샌더 이펙터, 재질별 시편, 표면조도계(Ra), (옵션) 액티브 컴플라이언스 이펙터. 3D 카메라는 보유분 활용.
