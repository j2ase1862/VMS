## 1. 검토 배경과 목적

캐나다 Maple Advanced Robotics Inc.(이하 MARI)의 CAD-free 로봇 샌딩·그라인딩 솔루션
**AARS** 도입을 검토하였으나 단가가 높아, 연구소 자체 개발 타당성을 검토한다.

본 보고서의 결론 범위:

1. MARI AARS 의 기능 분해와 당사 보유 자산(VMS / VMS.WeldTeach) 대비 격차 식별
2. 검토 시나리오 — **판매용 범용 제품으로 개발하되, ① 협동로봇을 두산으로 제한하고
   ② 자동 곡면 분할·결함 기반 적응 가공(격차 ④)과 노코드 플로차트 UI(격차 ⑤)를
   구현하는 경우** — 의 타당성 평가
3. 단계별 개발 로드맵 · 필요 장비 · 리스크 · 선행 과제

## 2. 대상 솔루션 분석 — MARI AARS

| 항목 | 내용 |
|---|---|
| 업체 | Maple Advanced Robotics Inc. (캐나다 온타리오 Richmond Hill) |
| 플랫폼 | AARS (Autonomous Adaptable Robot System) — 국내 공급은 HYM 경유로 추정 |
| 구조 | **Perception**(3D 레이저 스캔→점군) → **Reasoning**(점군에서 지오메트리·결함·공정 요구 분석) → **Planning**(CAD 없이 충돌 회피 경로 실시간 생성) |
| 제품군 | Scan&Go(적응 경로 계획) · Drag&Go(노코드 플로차트) · Plug&Play · Place&Go(턴키 셀) |

| 대상 공정 | 샌딩(목공 패널·캐비닛), 그라인딩(표면·수력터빈 블레이드), 폴리싱, 용접/절단, 검사 |
| 대상 시장 | 다품종 소량(HMLV) — 항공·자동차·조선·목공·금속·오일&가스 |
| 차별 소구 | 평균 프로그래밍 10분 · 배치 30배 단축 · CAD 불요 · 수동 티칭 불요 · 지그리스 |
| 검증 | 2025 하노버메세 로보틱스 어워드, CES 2026 Best of Innovation (AI 부문) |

**중요 사실:** 당사 WeldTeach 그라인딩 확장 명세는 애초에 HYM AARS 소개서를 참조 대응으로
작성되었고(명세 §2), 핵심 루프(스캔→영역→커버리지→포즈)는 이미 M1~M6 으로 구현·검증 완료
상태다. 즉 본 검토는 "제로 베이스 개발 가능성"이 아니라 **"보유 파이프라인의 제품화 격차"**
평가다.

## 4. 검토 시나리오 평가 — 두산 제한 + ④·⑤ 구현

### 4.1 두산 협동로봇 제한의 효과

**격차 ①·② 가 대부분 소멸한다.**

| 격차 | 두산 제한 후 |
|---|---|
| ① 로봇 연동 | 포스트프로세서 = **JSON → DRL**(두산 스크립트, 파이썬 유사) 변환기 하나. 공식 SDK·ROS2 드라이버·DART 시뮬레이터 존재 |
| ② 힘 제어 | **M 시리즈 전 관절 토크센서 내장** — `task_compliance_ctrl` / `set_desired_force` 등 힘 제어 API 가 로봇에 이미 있음. 당사 명세의 "힘 제어는 로봇단 책임" 설계와 정확히 정합. 고품질 연마 요구 시 액티브 엔드이펙터(PushCorp·FerRobotics 류) 추가 구매로 보강 |
| 판로(GTM) | 두산로보틱스 국내사 — 솔루션 파트너 생태계 등재 시 영업 채널 확보. AppSetup 로봇 벤더 선택지에 Doosan 기 반영 |

**트레이드오프 (명시):** 협동로봇은 산업용 대비 강성·속도가 낮아 **중(重)연삭·대형 스톡
제거는 제품 타깃에서 제외**된다 (MARI 의 수력터빈 블레이드급 불가). 타깃은 목공 샌딩·
용접비드 경연삭·폴리싱·소형 금속 피니싱 — 국내 HMLV 중소 제조와 정합하므로 시장 축소라기
보다 집중으로 판단.

### 4.2 격차 ④ — 3단계 분해 평가

한 덩어리로는 "대"지만 난이도가 다른 세 층으로 나뉜다.

| 층 | 내용 | 난이도 | 재료 |
|---|---|---|---|
| **Lv1** 자동 곡면 분할 | 법선·곡률 리전 그로잉 + RANSAC 프리미티브. 라쏘 선택을 "자동 분할 결과 승인/수정" UX 로 진화 | 중 (수 주~수 개월) | M1 법선·KdTree 재사용 |
| **Lv2** 결함 검출→영역 자동 지정 | 결함 마스크 → 점군 영역 → 커버리지 생성 배관 연결 | 중 | YOLO-Seg·SAM·포토메트릭 스테레오·마스크 크롭 체인 = **당사 차별화 강점** |
| **Lv3** 파라미터 적응 (얼마나 깎을지) | 재료·공구·힘·이송속도별 제거율 공정 지식 (MARI "physics-informed AI" 의 실체) | **대 — 데이터 축적 문제** | M5 영역별 파라미터·다층 패스가 그릇 역할. 초기 제품은 프리셋+수동 조정으로 출시, 현장 데이터로 고도화 |

### 4.3 격차 ⑤ — 노코드 플로차트 UI

VisionSetup 이 이미 도구 드래그·연결·실행 파이프라인 워크스페이스다. 스캔→분할→선택→
경로→실행 블록 플로차트는 그 경험의 변주 — **중소 규모, 리스크 낮음**.

### 4.4 제외한 격차 ③ 에 대한 필수 최소치

풀 모션 플래닝 생략은 협동로봇이라 감수 가능하다 (안전정지 = 사고가 아니라 멈춤).
단, **IK 도달성·관절 한계·특이점 검사는 생략 불가** — 없으면 내보낸 경로가 로봇에서
실패하여 제품 신뢰를 잃는다. 두산 기구학 공개 + DART 시뮬레이터로 "경로 생성 시 도달성
검사 + 시뮬레이터 프리뷰" 수준을 로드맵에 포함한다 (풀 플래닝 대비 소규모).

## 5. 단계별 개발 로드맵 (안)

> 기간은 소수 인원 + AI 보조 개발 전제의 개략 추정이며, P0 실증 결과에 따라 재산정한다.

| 단계 | 내용 | 산출물 / 판정 기준 | 개략 기간 |
|---|---|---|---|
| **P0 실기 실증** | 두산 M 시리즈 1대 확보 → JSON→DRL 스텁 → 내장 힘제어로 시편 샌딩 | 실기 데모 영상 (투자 설득 + 초기 영업 자료), 공정 성립 여부 판정 | 1~2개월 (로봇 확보 후) |
| **P1 도달성 + Lv1** | IK/관절한계/특이점 검사 + 자동 곡면 분할 | 분할 정확도 정량 검증, 경로 실기 성공률 | 2~3개월 |
| **P2 노코드 UI** | 플로차트 공정 에디터 (스캔~실행 블록) | 비개발자 셋업 시연 (AARS "10분 프로그래밍" 대응) | 2~3개월 |
| **P3 Lv2 결함 연동** | 결함 마스크 → 영역 → 경로 자동화 | 결함 유형 1~2종 자동 가공 데모 | 2~3개월 |
| **P4 Lv3 + 파일럿** | 공정 프리셋 테이블 (시편 실험) + 현장 파일럿 1개사 | 조도(Ra) 개선 정량, 파일럿 피드백 | 지속 (데이터 축적) |

**필요 장비 (견적 필요):** 두산 M 시리즈 1대(페이로드 고려 M1013급), 스핀들/샌더
엔드이펙터, 시편(재질별), 표면조도계(Ra), (옵션) 액티브 컴플라이언스 이펙터.
3D 카메라는 보유분(Mech-Eye) 활용.

### A.2 청구 내용 요지 (공개 공보 기준)

1. **곡면 피팅** — 점군/메시를 겹치는 서브패치로 분할, 다항식 피팅 후 RMSE 가 사용자
   임계 초과 시 재귀 세분화하여 곡면 방정식 계수 생성
2. **경로 계획** — 작업 영역에 정의한 경로 형상을 **피팅된 곡면 방정식에 투영**,
   호 길이 기반 웨이포인트 + 법선/접선 자세, 급회전을 원호로 치환(진동 저감)
3. **표면 가공** — 웨이포인트별 주곡률 방향·반경 산출, **Hertz 접촉 이론**으로
   일정 힘 벡터/트랙 폭 벡터 생성 (연마 접촉 일관성)

### A.3 당사 방식과의 대비 (예비 판단)

| 구성 | MARI 청구 방식 | 당사 구현 (WeldTeach M1~M6) |
|---|---|---|
| 표면 표현 | 다항식 곡면 방정식 (서브패치 재귀 피팅) | **2.5D 높이맵 그리드 + 쌍선형 보간** — 곡면 방정식 없음 |
| 경로 생성 | 피팅 곡면에 경로 형상 투영 | PCA 주평면 래스터 + **표면 호길이 스텝오버 보정** |
| 힘/접촉 | Hertz 접촉 모델로 자체 산출 | **로봇단 위임** (두산 내장 힘제어) — 자체 산출 안 함 |
| 급회전 처리 | 원호 치환 청구 | 세그먼트 분할 + 이동평균 평활 (원호 치환 없음) |

세 독립항 축(곡면 방정식 피팅·피팅 곡면 투영·Hertz 접촉) 모두 당사 경로에 해당
구성요소가 없어, **예비 판단으로는 청구항 회피 가능성이 높다**. 단 심사 과정에서
청구항이 보정되므로 KR 등록 청구항 확정 시 재대비가 필요하고, 위 판단은 법률 자문이
아니다.

### A.4 후속 조치

1. KIPRIS 에서 KR10-2024-7041198 심사 경과 모니터링 (의견제출통지·보정서·등록 여부)
2. KR 등록(또는 거절 확정) 시점에 변리사 FTO 의견서 — 등록 청구항 vs 당사 구현 대비
3. 개발 과정에서 위 세 축(곡면 방정식 피팅·곡면 투영·Hertz 모델) 도입은 피할 것 —
   현 설계 유지 시 자연 회피
