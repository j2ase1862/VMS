2. 캘리브레이션 (Calibration)

픽셀 좌표를 실제 mm 단위로 변환하기 위한 카메라 보정 작업이다. 본 모듈은 독립 윈도우로 제공되며, 결과를 현재 레시피의 Recipe.Calibration 슬롯에 적용한다. 이후 ImageRectifyTool · Caliper · CircleFit · Geometry 도구가 동일 슬롯을 참조해 mm 결과를 함께 출력한다.

2.1 Calibration Manager 진입

  1. VisionSetup 메인 메뉴 → Calibration 버튼 클릭.
  2. 독립 윈도우 Calibration Manager 가 열린다.
  3. 상단 Image Source 콤보박스에서 입력 소스를 선택한다.
Image Source설명사용 상황
File로컬 폴더의 이미지 파일 사용오프라인 검증, 사전 캡쳐 이미지
CameraCalibration Manager가 직접 카메라 연결VMS 메인 앱이 카메라를 점유하지 않을 때
VMS Shared FrameVMS 앱이 점유한 카메라의 SharedFrame을 차용운영 중 카메라 분리 없이 보정
주의 — 카메라 점유 충돌
VMS 메인 앱이 카메라에 연결된 상태에서 Camera 소스를 선택하면 연결이 끊어진다. 운영 중에는 VMS Shared Frame 사용을 권장한다.

2.2 Checkerboard 모드

OpenCV CalibrateCamera 알고리즘을 이용한 표준 카메라 캘리브레이션이다. 내부 왜곡 계수(distortion)와 카메라 매트릭스를 산출한다.

운영 절차

  1. Mode = Checkerboard 선택.
  2. 패턴 크기 입력: Inner Corners X × Y (예: 9×6 체커보드의 내부 코너 = 8×5).
  3. 한 칸의 실제 크기(mm) 입력 (Square Size mm).
  4. 여러 각도/위치에서 체커보드를 캡쳐 · 로드하여 다중 뷰 누적.
  5. Detect Corners 클릭 → 코너가 인식된 이미지만 누적 목록에 추가.
  6. 최소 8장 이상 누적 후 Calibrate 클릭.
  7. 결과 패널에 RMS Reprojection Error 표시 → 1.0 px 이하 권장.
  8. Apply to Current Recipe 클릭 → 현재 레시피에 캘리브레이션 저장.

2.3 N-Point 모드

이미지 평면 ↔ 월드 평면의 4점 이상 매칭으로 Homography 행렬을 산출한다. 평면 작업물에서 mm 변환이 필요할 때 사용한다.

  1. Mode = NPoint 선택.
  2. Image Canvas 가 PickPoint 모드로 전환된다 (십자 커서 표시).
  3. 이미지 상의 기준점을 클릭 → 우측 입력 패널에 World X / World Y (mm) 입력.
  4. 최소 4점 이상 입력 후 Calibrate 클릭.
  5. Homography 9개 원소가 결과 패널에 표시 → Recipe에 Apply.

2.4 SingleScale 모드

가장 단순한 보정. 알려진 길이의 기준선(예: 캘리퍼 자) 한 개로 픽셀당 mm 비율만 계산한다.

  1. Mode = SingleScale 선택.
  2. 이미지 위 기준선 두 끝점을 픽한다.
  3. 실제 길이(mm) 입력 → Calibrate.
  4. Scale (mm/pixel) 값이 산출되어 Recipe.Calibration 으로 저장.
SingleScale은 카메라 왜곡 보정이 불가능하다. 정밀 측정이 필요하면 Checkerboard를, 평면 정합이 필요하면 N-Point를 사용한다.

2.5 ImageRectifyTool — 파이프라인 첫 도구

위 캘리브레이션이 적용된 레시피에서, 카메라 왜곡과 평면 변환을 실제 이미지에 적용하기 위한 파이프라인 도구이다. 후속 도구는 보정된 이미지를 받는다.

파라미터설명기본값
Undistort왜곡 계수 적용 (Checkerboard 결과 사용)true
ApplyHomographyHomography 적용 (N-Point 결과 사용)false
ImageRectifyTool은 파이프라인 첫 위치에 배치해야 후속 도구의 좌표가 보정된 이미지 기준으로 동작한다.

2.6 mm 측정 변환

PR #5 부터 다음 도구의 결과 패널에 픽셀과 함께 mm 단위가 동시 출력된다.

도구mm 출력 항목
CaliperToolEdgePositionMm, PairWidthMm
CircleFitToolCenterXMm, CenterYMm, RadiusMm
GeometryTool각종 거리/길이 mm
Geometry3DTool3D 좌표 mm

Recipe.Calibration 이 비어있을 경우 mm 출력은 생략되고 픽셀 값만 표시된다.

3. ShapeMatchTool — PatMax-like

3.1 도구 개요

NCC(Normalized Cross-Correlation) 기반 회전 불변 패턴 매칭 도구. Cognex PatMax/PatQuick 의 대체 구현으로, 다음 가속 기법을 결합했다.

  • 이미지 피라미드 + Coarse-to-Fine 탐색 (PR #8c)
  • 회전 템플릿 사전 캐싱 — 동일 템플릿 반복 Run 시 추가 단축 (PR #8e)
  • 다중 인스턴스 + NMS 중복 제거 (PR #12)
  • Training Region / Search Region 분리 (PR #8b)
벤치마크 예: 1280×1024 이미지, AngleStep 2°, NumPyramidLevels 3 — 1.5 – 2.5초. PR #8e 이후 동일 템플릿 재실행 시 ~70% 단축.

3.2 단일 인스턴스 워크플로

  1. 학습용 이미지를 로드한다.
  2. Tool Palette → Shape Match 드래그 → 캔버스에 추가.
  3. 이미지 위에서 Training ROI(노란 사각형) 드래그 — 앵커 패턴 영역.
  4. 우측 파라미터 패널 → Train Template 클릭.
  5. 토스트 "템플릿 학습 완료" 표시, 미리보기 패치 갱신.
  6. 검색 이미지를 로드한다.
  7. Use Search Region 체크 → 캔버스에서 Search Region 드래그(시안 점선).
  8. Score Threshold 조정 (기본 0.7, 산업 환경 0.5–0.8 권장).
  9. Run 클릭 → 1순위 매칭이 오버레이로 표시.

3.3 다중 인스턴스 (NMS)

동일 패턴이 한 이미지에 여러 개 있을 때, 후처리 NMS로 중복을 제거하고 최대 N개를 반환한다.

파라미터설명권장
MaxInstances반환할 최대 인스턴스 수1 ~ 16
NmsDistanceFactorNMS 거리 임계비 (템플릿 대각선 × factor)0.3 ~ 0.6
TopCandidatesNMS 전 후보 풀 크기MaxInstances × 3 이상

3.6 성능 튜닝 체크리스트

  1. Search Region을 가능한 좁힌다 → 1차 효과가 가장 크다.
  2. AngleStep을 키운다 (1° → 2° → 3°).
  3. NumPyramidLevels을 2 → 3으로 늘린다 (큰 템플릿일수록 효과).
  4. 스케일 탐색이 불필요하면 MinScale = MaxScale = 1.0.
  5. 동일 템플릿 반복 사용 — 회전 캐시 자동 적용.

4. 컬러 도구

4.1 ColorExtractTool (HSV In-Range)

HSV 색공간의 H/S/V 6개 슬라이더로 정의된 박스 안의 픽셀만 추출하는 도구. 마스크 이미지를 출력하므로 후단 BlobTool과 연결해 개수/면적 검증에 사용한다.

워크플로

  1. 컬러 이미지 로드.
  2. Tool Palette → Color Extract 추가.
  3. Training ROI 드래그(추출 기준 색 영역).
  4. Train from ROI 클릭 → ROI 내부 HSV 평균 ± 2.5σ 자동 입력.
  5. 필요 시 H/S/V 슬라이더 미세조정 (전문가 모드에서 노출).
  6. (선택) Use Search Region + Search Region 지정.
  7. Run → 마스크 오버레이 + Pixel Count 표시.

주요 파라미터

파라미터범위의미
HueMin / HueMax0 – 179색상(OpenCV HSV)
SaturationMin / Max0 – 255채도
ValueMin / Max0 – 255명도
MorphKernelSize1 – 15마스크 노이즈 제거 (Open/Close)

ShowOverlay / OverlayOpacitybool / 0–1결과 이미지 위 표시 옵션

4.2 ColorMatchTool (Lab ΔE76)

학습 색 기준의 Lab 색차(ΔE76)가 임계 이하인 픽셀을 추출한다. 산업 환경의 동일 색상 재현성 검사에 유리하다.

학습 — 단일 픽셀

  1. Tool 추가 후 Pick Pixel 클릭.
  2. ImageCanvas 모드가 PickPoint로 전환(십자 커서).
  3. 기준 색 위치 클릭 → 픽셀 BGR → Lab 변환 후 SelectedModel의 MeanL/A/B 갱신.

학습 — ROI 평균

  1. Training ROI 드래그.
  2. Train from ROI → ROI 내부 평균 Lab가 모델에 반영.

주요 파라미터

파라미터권장의미

MorphKernelSize1 – 7마스크 후처리
UseSearchRegion—검색 영역 한정

4.3 다중 모델 관리

ColorExtract / ColorMatch 모두 한 도구 안에 여러 컬러 모델을 가질 수 있다. 동일 색이 조명·질감에 따라 미세하게 다르게 보일 때 모델을 추가로 등록하면 Run 시 OR 합집합으로 결합한다.

  1. 모델 목록 우측 + Add Model 클릭 → 새 항목 생성.
  2. 각 모델 선택 후 학습 (픽 또는 ROI).
  3. 각 항목 IsEnabled 체크로 ON/OFF.
  4. 항목 우측에 학습 색 미니 패치 + 마스크 픽셀 수 인라인 표시.
한 도구에 완전 다른 색을 등록하지 말 것. 그 경우는 도구를 분리해야 결과 해석이 명확하다. 동일 색상의 미세 변형만 같은 도구에 두는 것이 권장 사용 패턴.

5. 3D 포인트클라우드

3D 카메라(structured light / stereo) 의 출력을 받아 처리하는 파이프라인 도구 3종이다. 입력은 VisionService.CurrentPointCloud(PointCloudData), 출력 역시 같은 슬롯을 갱신해 다음 도구로 전달한다.

5.1 PointCloudFilterTool

다운샘플링과 이상치 제거를 한 도구에서 수행한다.

파라미터설명권장
EnableVoxelGridVoxelGrid 다운샘플링 사용 여부true
VoxelSize복셀 한 변(mm)1.0 – 3.0
EnableSorStatistical Outlier Removal 사용 여부true
SorK이웃 점 수(KNN)20 – 50
SorStddev표준편차 임계1.0 – 2.0

검증 절차

  1. .vpc 포인트클라우드 로드 → 3D 뷰에 포인트 표시.
  2. Tool 추가 → 위 파라미터 설정 → Run.
  3. 결과 패널의 "Filtered Point Count" 가 입력 대비 명확히 감소함을 확인.

5.2 PointCloudRegistrationTool (ICP)

참조 클라우드(Reference) 와 현재 클라우드의 ICP(Iterative Closest Point) 정합을 수행한다.

파라미터설명
ReferencePath정답 .vpc 파일 경로
MaxIterations최대 반복 (기본 50)
Tolerance수렴 임계 (1e-5 권장)
ApplyTransformToSourcetrue 면 정합된 클라우드를 CurrentPointCloud로 갱신

출력

  • 4×4 변환 행렬 (Rotation + Translation)
  • Mean Squared Error
  • 수렴 반복 횟수

5.3 PointCloudClusterTool

Euclidean Clustering 으로 인접 포인트 그룹을 분리한다. 그리드 해싱 + BFS로 구현되어 큰 클라우드도 빠르게 처리한다.

파라미터설명
Tolerance같은 클러스터로 인정할 이웃 거리(mm)
MinPoints / MaxPoints클러스터 점 수 범위
MaxReportedClusters결과 보고 상한
OutputModeLargestCluster · AllClusters · Report

6.3 ONNX 모델 워밍업

레시피 Load 시 RecipeService.PrefetchDeepLearningModels 가 모든 DL 도구의 ONNX 모델을 백그라운드로 미리 메모리에 적재한다. 따라서 첫 Run의 5초+ 지연이 사실상 사라진다.

sequenceDiagram
    participant U as 사용자
    participant R as RecipeService
    participant C as OnnxEngineCache
    participant V as VisionService

        R->>C: Prefetch{Yolo/Seg/...}(modelPath)

    end
    R-->>U: Recipe loaded
    U->>V: Run
    V->>C: GetEngine(modelPath)
    C-->>V: 캐시 hit (즉시 반환)
    V-->>U: 결과

7. UX 개선

7.1 HelpIcon 호버 팝업

도구 팔레트의 도구 아이콘 옆 ? 아이콘 또는 파라미터별 ? 아이콘에 마우스를 올리면 300 ms 지연 후 팝업이 열려 한국어 설명을 표시한다.

  • 팝업 본문 클릭 → 윈도우가 확장되어 더 긴 설명 표시.
  • X 버튼 클릭 → 팝업 닫힘.
  • 마우스가 아이콘 또는 팝업 안에 있을 때는 닫히지 않는다 (StaysOpen).
  • 휠 스크롤로 긴 내용 탐색 가능.

7.2 ImageCanvas 점 픽업 모드

PR #3 / PR #11c에서 도입된 EditMode.PickPoint. Calibration N-Point 및 ColorMatch Pick Pixel에서 사용된다.

  • 좌클릭 시 PointPicked 이벤트 발생 → 좌표가 VM으로 전달.
  • ESC 또는 모드 종료 버튼으로 복귀.
