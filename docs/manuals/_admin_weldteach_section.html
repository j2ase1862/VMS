      9. 9. VMS.WeldTeach — 로봇 티칭 도구 (내부 전용)

      GS 인증 범위 제외: WeldTeach 는 기술 검증용 PoC 앱입니다. 배포 MSI 에 포함되지 않고, 사용자 매뉴얼에도 싣지 않으며, GS 인증 시험 대상이 아닙니다. 이 장은 개발·관리자만 봅니다. 제외 사유는 §9.8 참조.

      WeldTeach 는 로봇이 용접·그라인딩할 경로를 컴퓨터 앞에서 미리 만들어 보는 프로그램입니다 (오프라인 티칭). 로봇을 세워 두고 티칭 펜던트로 한 점씩 가르치는 대신, 도면(CAD)이나 3D 카메라 스캔에서 경로를 만들어 JSON 파일로 내보내면 로봇 제어기가 그 파일을 읽어 움직입니다. 공정에 따라 두 모드로 나뉩니다.

      공정 모드입력만드는 것비고
      용접STEP 도면 (CAD)용접선(심)을 따라가는 토치 자세 목록도면↔실물 맞추기(정합)가 필요
      그라인딩3D 카메라 스캔 점군선택한 면을 빈틈없이 덮는 왕복 경로 + 공구 자세도면 불필요 — 스캔에서 바로 만듦

      9.1 개요 · 인증 범위 제외

      이 앱은 "로봇 오프라인 티칭이 우리 스택으로 가능한가"를 검증하기 위한 PoC 로, 제품 라인(VMS 클라이언트)과는 별개입니다. 핵심 검증은 끝났고 (용접: STEP 커널·엣지 체이닝·ICP 정합, 그라인딩: 커버리지 경로·공구 포즈 M1~M6), 실제 3D 카메라 스캔 파일 확인과 로봇 실기 연동이 남아 있습니다.

      9.2 실행 방법

      1. 개발 PC 에서 저장소를 빌드합니다: dotnet build VMS.WeldTeach\VMS.WeldTeach.csproj
      2. VMS.WeldTeach\bin\Debug\net8.0-windows7.0\VMS.WeldTeach.exe 를 실행합니다.
      3. 또는 VisionSetup 상단 메뉴의 [WeldTeach] 로 엽니다. 이 메뉴는 WeldTeach 실행 파일이 있는 PC 에서만 나타납니다 — 배포 MSI 에는 WeldTeach 가 포함되지 않으므로 GS 인증 환경·현장 설치본에서는 메뉴 자체가 보이지 않고, 개발·테스트 PC 에서는 Release 실행본에서도 쓸 수 있습니다. (VisionSetup 실행 중에 WeldTeach 를 새로 빌드했다면 VisionSetup 을 재시작해야 메뉴가 뜹니다.)
      참고: 첫 STEP 로드는 CAD 커널 초기화 때문에 몇 초 걸릴 수 있습니다.

      9.3 용접 모드 — CAD 경로 티칭

      1. 툴바 공정 모드에서 [용접] 을 선택하고 [STEP 열기] 로 도면을 엽니다. 연습용으로는 [샘플 시편 생성] 이 T-필릿 시편을 만들어 줍니다.
      2. 모델에서 용접할 모서리를 클릭합니다. 매끄럽게 이어진 모서리는 자동으로 한 경로로 묶이고(체이닝), 목록에 추가됩니다. 목록 순서 = 용접 순서이며, 같은 경로를 다시 클릭하면 해제됩니다.
      3. 포즈 간격(mm)을 정합니다. 곡률 적응을 켜면 직선은 넓게, 곡선은 자동으로 촘촘하게 찍힙니다. 선택한 경로의 포즈는 노란 점 + 토치 방향 화살선으로 표시됩니다.
      4. 실물과 맞추려면: [점군 열기] 로 스캔을 불러오고 [CAD 정합 실행 (ICP)] 을 누릅니다. 정합이 끝나면 점군이 도면 위에 겹쳐 보이고 평균 오차(RMSE)가 표시됩니다.
      5. [경로 내보내기 (JSON)] — 정합돼 있으면 로봇 좌표계로 변환해 저장합니다.

      9.4 그라인딩 모드 — 점군 커버리지

      도면 없이, 3D 카메라가 찍은 점군에서 직접 갈아낼 면을 지정합니다.

      1. 공정 모드에서 [그라인딩] 선택 → [점군 열기](.vpc/PLY/XYZ) 또는 합성 표면(평면·경사·원통·물결·구멍 패널) + [생성]. 점군을 넣으면 정리(노이즈· 이상치 제거, 방향 추정)가 자동으로 실행됩니다.
      2. 뷰포트를 드래그해 가공 영역을 선택합니다 — 라쏘(올가미) 또는 브러시. Shift+드래그 = 영역에 추가, Ctrl+드래그 = 제거. 영역 목록 순서가 곧 가공 순서입니다.
      3. 공구 직경과 겹침(%)을 넣으면 스텝오버(줄 간격)가 계산됩니다. 예: 직경 50mm · 겹침 30% → 35mm 간격. 경사·곡면에서도 실제 표면 간격이 유지되도록 자동 보정됩니다.
      4. 리드각(공구를 진행 방향으로 눕히는 각, 기본 10°)·틸트각·패스 수·패스당 깊이를 정하고 [커버리지 생성] — 초록 왕복 경로와 청록 공구 축이 표시됩니다.
      5. [경로 내보내기 (JSON)] — 영역·파라미터·패스별 포즈가 저장됩니다.

      9.5 뷰포트 조작 (양 모드 공통)

      동작조작
      회전우클릭 드래그
      이동(팬)Shift+우클릭 드래그, 또는 휠(가운데)클릭 드래그
      확대/축소휠 스크롤, Ctrl+우클릭 드래그

      좌클릭은 모서리 선택(용접)·영역 선택(그라인딩)에 쓰이므로 카메라에는 배정돼 있지 않습니다. 같은 안내가 뷰포트 왼쪽 위에 항상 표시됩니다.

      9.6 로봇 좌표 변환 (T_cam2base)

      그라인딩 경로는 카메라가 본 좌표로 만들어집니다. 로봇이 그대로 쓰려면 "카메라 좌표 → 로봇 베이스 좌표" 변환 행렬이 필요하고, 이 행렬은 핸드-아이 캘리브레이션으로 구합니다 (절차는 VMS_HandEye_Calibration_Manual.md 참조).

      1. 캘리브레이션 결과 4×4 행렬 파일을 준비합니다 — JSON 2차원 배열, 숫자 12·16개 평탄 배열/텍스트, 또는 tCam2BaseRowMajor 키가 있는 JSON (WeldTeach 가 내보낸 경로 파일을 그대로 다시 넣어도 됩니다). 모두 행 우선, mm.
      2. 그라인딩 패널의 [행렬 불러오기] 로 엽니다. 행렬이 강체 변환이 아니면 (크기 변형이 섞였거나 m↔mm 단위가 틀리면) 이유를 알려주고 거부합니다.
      3. 이후 [경로 내보내기] 는 모든 포즈를 로봇 베이스 좌표로 변환해 저장하고, 쓴 행렬도 파일에 함께 기록합니다. [해제] 를 누르면 다시 카메라 좌표계로 내보냅니다. 현재 상태는 버튼 아래에 항상 표시됩니다.

      9.7 자가 검증 · 진단

      화면 없이 전체 기능을 자동 점검할 수 있습니다 — 회귀 확인용.

      명령하는 일
      --selftest용접(STEP 왕복·체이닝·포즈·ICP)과 그라인딩(M1~M6: 전처리·영역 선택·커버리지·곡면 보정·포즈·.vpc 체인·행렬)을 전부 점검 → %TEMP%\weldteach_selftest.log 마지막 줄들이 전부 OK 여야 정상
      --weldcap <png> / --grindcap <png>용접/그라인딩 화면을 자동 재현해 PNG 로 캡처 (UI 변경 확인용)
      --switchcap <접두사>모드 전환 4단계를 캡처해 이전 그래픽 잔상 회귀를 확인
      --open <step> [--capture <png>]지정 STEP 을 GUI 와 동일 경로로 로드·캡처

      9.8 알려진 제약 (= 인증 제외 사유)

      • CAD 커널 라이선스 불명 — 용접 모드가 쓰는 NuGet Occt.NET 패키지는 배포자의 라이선스 명시가 없어 제품 배포에 쓸 수 없습니다. PoC 전용이며, 제품화 시 OCCT 직접 빌드 또는 상용 커널로 교체가 전제입니다. 그라인딩 모드는 이 커널을 쓰지 않으므로 해당 리스크가 없습니다.
      • 실카메라 스캔 미확인 — 자가 검증은 VMS [Save 3D] 와 같은 .vpc 형식을 실제 파일로 거치지만, 실장비가 찍은 파일로는 아직 확인하지 못했습니다 (현장 장비 필요).
      • 로봇 실기 연동 없음 — 내보낸 JSON 을 로봇 제어기로 보내는 단계는 벤더 선정 후 개발. 힘 제어(그라인딩 접촉력)는 로봇단 책임으로 설계돼 있습니다.
      • 배포 MSI·업데이트 채널에 포함되지 않으며, 실행은 개발 빌드에서만 합니다 (§9.2).
