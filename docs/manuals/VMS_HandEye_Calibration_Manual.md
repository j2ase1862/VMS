## 1. 개요

Hand-Eye 캘리브레이션은 **카메라와 로봇 사이의 공간적 관계(T_tcp_cam)**를 수학적으로 결정하는 과정입니다. 이 변환 행렬이 정확해야 카메라로 관측한 물체의 위치를 로봇 좌표계에서 정확하게 표현할 수 있습니다.

### 전체 흐름

```
사전 준비 → 위저드 실행 → 보드 설정 → 데이터 수집 (15~20회) → 캘리브레이션 → 결과 저장
```

| 단계 | 설명 |
|------|------|
| 사전 준비 | 체스보드 타겟 준비, 로봇/카메라 연결 |
| Setup | 체스보드 크기, 격자 간격, 알고리즘 선택 |
| Collect | 로봇을 다양한 자세로 이동 → Capture 버튼으로 포즈+이미지 동시 수집 |
| Calibrate | 카메라 내부 파라미터 + Hand-Eye 변환 행렬 자동 계산 |
| Save | 결과를 JSON 파일로 저장 → MultiView 시스템에 자동 적용 |

### AX=XB 문제란?

Hand-Eye 캘리브레이션은 "AX=XB" 방정식을 푸는 것입니다:
- **A**: 두 로봇 포즈 사이의 상대 변환 (로봇에서 측정)
- **B**: 두 카메라 포즈 사이의 상대 변환 (체스보드 검출로 계산)
- **X**: 카메라-로봇 TCP 간 변환 (구하려는 값)

## 2. 사전 준비

### 2-1. 체스보드 타겟 준비

| 항목 | 권장 사양 |
|------|-----------|
| 크기 | 내부 코너 9x6 이상 |
| 격자 크기 | 20~30mm (측정 정밀도에 따라) |
| 재질 | 무광 인쇄, 평탄한 판에 부착 (휘어짐 방지) |
| 고정 | 작업대에 고정하거나 바닥에 평탄하게 놓기 |

> **중요**: 체스보드는 캘리브레이션 중 **움직이면 안 됩니다**. 견고하게 고정하세요.

격자 크기는 실제 인쇄물의 **한 칸의 변 길이**를 자(캘리퍼스)로 정밀하게 측정합니다.

### 2-2. 로봇 연결

1. VisionSetup 메인 화면에서 로봇 IP/포트/제조사를 설정합니다.
2. **Connect** 버튼을 눌러 로봇과 연결합니다.
3. 상태 표시등이 **초록색**으로 변하면 연결 완료입니다.

### 2-3. 카메라 연결

1. 카메라 목록에서 사용할 카메라를 선택합니다.
2. **Connect Camera** 버튼으로 카메라를 연결합니다.
3. 테스트 촬영으로 이미지가 정상적으로 들어오는지 확인합니다.

## 3. 위저드 실행 방법

1. VisionSetup 메인 화면에서 **MultiView Setup** 창을 엽니다.
2. **Hand-Eye Calibration** 섹션에서 **Calibrate** 버튼을 클릭합니다.

```
[Hand-Eye Calibration 경로 표시] [...] [Calibrate]
```

3. 로봇과 카메라가 모두 연결되어 있어야 합니다. 연결되지 않은 경우 경고 메시지가 표시됩니다.
4. **Hand-Eye Calibration Wizard** 창이 열립니다.

### 화면 구성

```
+------------------------------------------------------------------+
| 0. Setup  ►  1. Collect  ►  2. Calibrate  ►  3. Save            |
+------------------------------------------------------------------+
|  [설정/컨트롤 패널]  |  [이미지 미리보기]                          |
|                      |                                            |
|  Step별 입력 필드     |  체스보드 코너 검출 결과                     |
|  및 버튼             |  오버레이 표시                               |
|                      |                                            |
+------------------------------------------------------------------+
| 상태 메시지                                                       |
+------------------------------------------------------------------+
|                                    [◄ Previous] [Next ►]          |
+------------------------------------------------------------------+
```

- **좌측**: 현재 Step에 해당하는 설정 및 컨트롤
- **우측**: 촬영된 이미지와 체스보드 코너 오버레이 미리보기
- **상단**: 4단계 진행 표시기 (현재 단계 주황색 강조)
- **하단**: 상태 메시지 + Previous/Next 네비게이션 버튼

## 4. Step 0: Setup — 보드 파라미터 설정

### 설정 항목

| 파라미터 | 설명 | 기본값 | 비고 |
|----------|------|--------|------|
| **Corners X** | 체스보드 내부 코너 수 (가로) | 9 | 격자 칸 수 - 1 |
| **Corners Y** | 체스보드 내부 코너 수 (세로) | 6 | 격자 칸 수 - 1 |
| **Square Size (mm)** | 격자 한 칸의 실제 크기 | 25.0 | 실측값 입력 필수 |
| **Method** | 캘리브레이션 알고리즘 | TSAI | 아래 참조 |

### 코너 수 세는 방법

체스보드의 "내부 코너"란 흑백 사각형이 만나는 교차점입니다.

```
예: 10x7 칸 체스보드 → Corners X = 9, Corners Y = 6
    (칸 수에서 각각 1을 빼면 내부 코너 수)
```

### 캘리브레이션 알고리즘 선택

| Method | 특징 | 권장 사용 |
|--------|------|-----------|
| **TSAI** | 가장 일반적, 안정적 | 기본 선택 (대부분의 경우) |
| **PARK** | TSAI와 유사한 정밀도 | TSAI 결과가 불안정할 때 대안 |
| **HORAUD** | 회전 벡터 기반 | 넓은 회전 범위에 유리 |
| **ANDREFF** | 선형 해법 | 빠르지만 정밀도 약간 낮음 |
| **DANIILIDIS** | 듀얼 쿼터니언 기반 | 회전+이동 동시 최적화 |

> 일반적으로 **TSAI**를 사용하고, 결과가 불만족스러우면 다른 방법을 시도해 보세요.

설정을 마쳤으면 **Next** 버튼을 눌러 Step 1로 이동합니다.

## 5. Step 1: Collect — 데이터 수집

이 단계에서 로봇을 다양한 자세로 이동시키며 **포즈+이미지** 쌍을 수집합니다.

### 수집 절차

1. **로봇을 이동**합니다: 티치 펜던트 또는 조그 조작으로 카메라가 체스보드를 다양한 각도에서 바라보도록 이동합니다.
2. 로봇이 **완전히 정지**한 것을 확인합니다.
3. 위저드에서 **Capture** 버튼을 클릭합니다.
4. 시스템이 자동으로 수행하는 작업:
   - 로봇 컨트롤러에서 현재 TCP 포즈(X, Y, Z, Rx, Ry, Rz) 읽기
   - 카메라에서 이미지 촬영
   - 체스보드 코너 검출 (서브픽셀 정밀도)
   - 데이터 쌍 저장
5. 성공 시: 우측에 코너 오버레이 이미지가 표시되고, 하단 DataGrid에 수집 기록이 추가됩니다.
6. 실패 시: "체스보드를 검출할 수 없습니다" 메시지 → 로봇 위치/각도를 조정하고 다시 시도합니다.
7. 위 과정을 **최소 15~20회** 반복합니다.

### 버튼 설명

| 버튼 | 기능 |
|------|------|
| **Capture** | 현재 포즈에서 이미지+포즈 동시 수집 |
| **Remove** | 마지막으로 수집한 데이터 1개 제거 |
| **Clear** | 모든 수집 데이터 초기화 |

### DataGrid 표시 항목

| 열 | 설명 |
|----|------|
| **#** | 데이터 순번 |
| **Pose** | 로봇 TCP 위치 (X, Y, Z) 요약 |
| **Corners** | 검출된 코너 수 (예: 54 = 9x6) |

### 수집 최소 요건

- **최소 3개** 이상 수집해야 Step 2로 진행 가능
- **권장 15~20개** — 더 많을수록 정밀도 향상

수집을 마쳤으면 **Next** 버튼을 눌러 Step 2로 이동합니다.

## 6. Step 2: Calibrate — 캘리브레이션 실행

### 실행 방법

1. **Run Calibration** 버튼을 클릭합니다.
2. 진행 표시줄이 표시되며, 백그라운드에서 다음이 순차적으로 실행됩니다:
   - **카메라 내부 파라미터 캘리브레이션** (CameraMatrix, DistCoeffs 자동 계산)
   - **Hand-Eye 캘리브레이션** (AX=XB 솔버)
3. 완료 후 결과가 표시됩니다.

### 결과 해석

| 항목 | 설명 | 기준값 |
|------|------|--------|
| **Reprojection Error** | 재투영 오차 (px) | < 1.0 px 양호, < 0.5 px 우수 |
| **Result Matrix** | T_tcp_cam 4x4 변환 행렬 | 단위: mm(이동), 무차원(회전) |

결과 행렬 예시:

```
[   0.9998    0.0134   -0.0156    0.0000]
[  -0.0131    0.9998    0.0143    0.0000]
[   0.0158   -0.0141    0.9998    0.0000]
[  15.2340  -42.1567   85.3210    1.0000]
```

- 상위 3x3: 회전 행렬 (카메라→TCP 방향)
- 하단 1x3 (15.23, -42.16, 85.32): 평행이동 (mm)

### 결과가 불만족스러운 경우

1. **Method 변경**: Step 0으로 돌아가 다른 알고리즘 선택 후 재실행
2. **데이터 추가**: Step 1으로 돌아가 추가 데이터 수집
3. **불량 데이터 제거**: Step 1에서 특이한 포즈의 데이터를 Remove

결과에 만족하면 **Next** 버튼을 눌러 Step 3으로 이동합니다.

## 7. Step 3: Save — 결과 저장

### 저장 방법

1. **Save as JSON...** 버튼을 클릭합니다.
2. 파일 저장 다이얼로그에서 저장 위치와 파일명을 지정합니다.
   - 기본 파일명: `hand_eye_calibration.json`
3. 저장 완료 시 파일 경로가 표시됩니다.

### 저장 파일 내용 (JSON)

```json
{
  "Method": "TSAI",
  "ReprojectionError": 0.342,
  "BoardCornersX": 9,
  "BoardCornersY": 6,
  "SquareSize": 25.0,
  "PairCount": 18,
  "Matrix": [
    0.9998, 0.0134, -0.0156, 0.0,
    -0.0131, 0.9998, 0.0143, 0.0,
    0.0158, -0.0141, 0.9998, 0.0,
    15.234, -42.157, 85.321, 1.0
  ]
}
```

### Summary 표시

저장 후 화면에 캘리브레이션 요약 정보가 표시됩니다:
- Data Pairs: 수집 데이터 수
- Method: 사용된 알고리즘
- Error: 재투영 오차
- Board: 보드 크기 및 격자 간격

## 8. 캘리브레이션 결과 적용

위저드를 닫으면 저장된 JSON 파일 경로가 **MultiView Setup 창**의 Hand-Eye Calibration 경로에 자동으로 설정됩니다.

```
[hand_eye_calibration.json 경로] [...] [Calibrate]
 ● Calibrated                       ← 초록색으로 변경
```

이후 MultiView 3D 스캔 시 이 행렬이 자동으로 적용되어 로봇 포즈 기반 포인트 클라우드 정합에 사용됩니다.

### 기존 캘리브레이션 파일 로드

외부에서 수행한 캘리브레이션 결과도 같은 JSON 형식이면 **[...]** 버튼으로 직접 로드할 수 있습니다.

## 9. 캘리브레이션 팁 및 권장 사항

### 로봇 자세 다양성

캘리브레이션 정밀도를 높이려면 **다양한 자세**에서 데이터를 수집해야 합니다:

| 권장 | 비권장 |
|------|--------|
| 다양한 거리 (가까이/멀리) | 한 거리에서만 촬영 |
| 다양한 각도 (기울임/회전) | 정면에서만 촬영 |
| 이미지 전체에 보드 분포 | 이미지 중앙에만 보드 |
| 15~20개 이상 수집 | 최소 3개만으로 진행 |

### 촬영 시 주의 사항

- 로봇이 **완전히 정지**한 후 Capture — 진동이 있으면 블러 발생
- 체스보드가 **이미지 안에 완전히 보여야** 함 — 잘리면 검출 실패
- **조명이 균일**해야 함 — 반사광/그림자 방지
- 체스보드가 **평탄**해야 함 — 구부러진 보드는 정밀도 저하
- 촬영 중 **보드를 움직이지 않기** — 모든 촬영에서 보드 고정

### 정밀도 검증

캘리브레이션 후 실제 검증 방법:

1. 로봇을 알려진 위치로 이동
2. 카메라로 기준점 촬영
3. 변환 행렬을 적용하여 계산된 로봇 좌표와 실제 좌표 비교
4. 오차가 1mm 이내이면 양호

## 10. 문제 해결 (FAQ)

### Q: "로봇이 연결되어 있지 않습니다" 메시지가 나옵니다

**A**: MultiView Setup 창 상단에서 먼저 로봇을 Connect 해야 합니다.
- IP/Port/제조사 설정 확인
- Connect 버튼 클릭 → 초록색 표시등 확인
- 그래도 안 되면 로봇 컨트롤러의 네트워크 설정 확인

### Q: "카메라가 연결되어 있지 않습니다" 메시지가 나옵니다

**A**: VisionSetup 메인 화면에서 카메라를 먼저 연결하세요.

### Q: Capture 시 "체스보드를 검출할 수 없습니다"가 반복됩니다

**A**: 다음을 확인하세요:
- Corners X/Y 값이 실제 체스보드와 일치하는지 확인 (가장 흔한 원인)
- 체스보드가 이미지 안에 완전히 보이는지 확인
- 조명이 충분한지, 반사광이 없는지 확인
- 이미지가 너무 흐리거나 어둡지 않은지 확인
- 체스보드를 카메라에 더 가까이/멀리 이동하여 시도

### Q: "로봇 포즈를 읽을 수 없습니다"가 나옵니다

**A**: 로봇 통신이 불안정합니다:
- 로봇이 에러 상태가 아닌지 확인
- 통신 프로토콜 설정이 올바른지 확인 (Vendor Native / Modbus-TCP / Custom Socket)
- 네트워크 연결 상태 확인

### Q: 캘리브레이션 오차가 너무 큽니다 (> 2.0 px)

**A**: 데이터 품질 문제입니다:
- 데이터 수를 20개 이상으로 늘려 보세요
- 자세 다양성을 높이세요 (다양한 거리/각도)
- 체스보드가 평탄한지 확인하세요
- 이미지가 선명한지 확인하세요 (초점, 블러)
- 다른 Method (PARK, DANIILIDIS 등)를 시도해 보세요

### Q: "최소 3개 이상의 데이터가 필요합니다" 메시지가 나옵니다

**A**: Step 1에서 최소 3개 이상의 데이터를 수집해야 Step 2로 진행할 수 있습니다. Capture 버튼으로 추가 수집하세요.

### Q: 저장한 JSON 파일을 다시 사용할 수 있나요?

**A**: 네. MultiView Setup 창의 Hand-Eye Calibration 경로에서 [...] 버튼으로 기존 JSON 파일을 로드할 수 있습니다. 위저드를 다시 실행할 필요 없이 이전 캘리브레이션 결과를 바로 사용할 수 있습니다.

### Q: 시뮬레이션 모드에서도 캘리브레이션이 가능한가요?

**A**: 기능적으로는 실행 가능하지만, 시뮬레이션 로봇의 포즈 데이터는 가상이므로 실제 정밀한 캘리브레이션 결과를 기대할 수 없습니다. 실제 로봇+카메라 환경에서 수행하는 것을 권장합니다.
