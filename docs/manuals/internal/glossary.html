본문에 자주 나오는 낱말을 일의 순서대로 모았습니다 — 촬영, 검사 도구, 레시피 · 운전, 3D · 확장 옵션, 시스템 순입니다. "화면" 은 그 낱말이 나오는 곳, "더 읽기" 는 깊이 알고 싶을 때 볼 바깥 자료입니다.

ROI Region of Interest, 검사 영역
사진에서 도구가 실제로 보는 부분. 좁힐수록 빠르고 엉뚱한 곳을 덜 잡습니다. 화면: VisionSetup 이미지 위 사각형(§5.5).
노출 · 게인 Exposure · Gain
노출은 셔터가 열린 시간(밝기와 번짐을 함께 정함), 게인은 신호 증폭(밝아지지만 잡음도 커짐). 화면: VMS 카메라 설정 창(§4.5), VisionSetup 스텝 카메라 설정(§5.3). 더 읽기: Exposure (Wikipedia)
시야 · 해상도 FOV · mm/px
카메라가 한 번에 보는 크기와, 한 화소가 실제로 몇 mm 인지. 잡을 결함의 크기를 정합니다(§1.7).
캘리브레이션 Calibration
화소 좌표를 mm 로 바꾸는 기준을 만드는 일. 체커보드 · 원 격자 · 두 점 거리 등으로 합니다. 화면: VisionSetup 캘리브레이션(§5.9). 더 읽기: Camera resectioning (Wikipedia)
트리거 Trigger
"지금 찍어라" 신호. 센서 · 설비 신호를 IO 보드(◆PLC)로 받아 찍는 외부 트리거가 기본입니다. 화면: 시퀀스 편집기 Input Check 노드(§5.10).
◆라인스캔 카메라 Line Scan
한 줄씩 찍어 움직이는 제품을 이어 붙이는 카메라. 롤러 · 시트처럼 계속 흐르는 표면에 씁니다. 화면: 설정 마법사 카메라 단계(§3.4), 사이드 패널 Roller Inspection(§4.6). 더 읽기: Line-scan camera (Wikipedia)
이진화 Threshold
밝기 기준값으로 사진을 흑과 백 두 값으로 나누는 것. 블롭 분석 앞 단계로 씁니다(§6.2). 더 읽기: Thresholding (Wikipedia)
히스토그램 Histogram
밝기마다 화소가 몇 개인지 센 그래프. 사진이 너무 어둡거나 하얗게 날아갔는지 봅니다(§6.2).
에지 Edge
밝기가 급하게 바뀌는 경계. 치수 측정과 패턴 매칭의 기준입니다(§6.2 · §6.6).
블롭 Blob
이진화한 사진에서 붙어 있는 덩어리. 개수 · 넓이 · 위치로 부품 유무 · 이물을 판정합니다(§6.5 · §7.1). 더 읽기: Blob detection (Wikipedia)
캘리퍼 Caliper
지정한 선을 따라 에지를 찾아 두 에지 사이 거리를 재는 도구(§6.6 · §7.2).
패턴 매칭 Feature Match · Shape Match
미리 가르쳐 둔 모양을 사진에서 찾아 위치 · 각도 · 점수를 내는 것. Feature Match 는 에지 특징, Shape Match 는 밝기 상관(NCC)을 씁니다(§6.3). 더 읽기: Template matching (Wikipedia)
위치 보정 Fixture
패턴 매칭으로 찾은 위치 · 각도를 기준으로 뒤 도구의 ROI 를 함께 옮기는 것. 제품이 조금씩 다른 자리에 와도 같은 곳을 검사합니다(§7.3).
얼라인 Align, ΔX · ΔY · Δθ
기준 위치 대비 지금 위치가 얼마나 어긋났는지(가로 · 세로 · 각도) 계산하는 것. ◆로봇 · 스테이지 보정량으로 보낼 수 있습니다(§6.4 · §7.8).
OCR · OCV
OCR 은 글자를 읽는 것, OCV 는 정해진 글자가 맞게 찍혔는지 확인하는 것(§6.7 · §7.6). 더 읽기: 위키백과 — 광학 문자 인식
코드 판독 Barcode · QR · DataMatrix
1차원 바코드와 2차원 코드를 읽는 것. DataMatrix 는 작은 부품 각인에 많이 씁니다(§6.8 · §7.5). 더 읽기: Data Matrix (Wikipedia)
색 공간 HSV · Lab · ΔE
색을 숫자로 나타내는 방식. HSV 는 색상 · 채도 · 명도로 색을 고르기 쉽고, Lab 의 ΔE 는 두 색이 사람 눈에 얼마나 달라 보이는지를 냅니다(§6.13 · §7.4). 더 읽기: Color difference (Wikipedia)
딥러닝 검사 도구
학습된 모델(ONNX)로 검출 · 분류 · 이상탐지 · 분할을 하는 도구. 규칙으로 적기 어려운 흠집 · 이물에 씁니다(§6.11 · 10장). 개념은 MLOps 매뉴얼 1부에 쉽게 풀어 두었습니다.
ONNX
여러 학습 도구가 같이 쓰는 모델 파일 표준. 딥러닝 도구의 Model Path 에 지정합니다. 더 읽기: onnx.ai
TensorRT
NVIDIA GPU 에서 딥러닝 추론을 빠르게 하는 엔진. Inference Settings 에서 고릅니다(§10.2). 더 읽기: ONNX Runtime — TensorRT
◆모델 참조 model://
레시피가 모델 파일 대신 MLOps 레지스트리의 모델을 가리키는 주소. model://계열ID@production(운영 추종) 또는 @버전번호(고정). 화면: 딥러닝 도구 [레지스트리…](§5.13).
레시피 · 스텝 Recipe · Step
레시피는 한 제품의 검사 설정 전체, 스텝은 그 안의 촬영 한 번(카메라 설정 + 도구 목록)입니다. 화면: VisionSetup Recipe Manager(§5.3).
판정 · Result 연결
도구마다 Pass/Fail 을 내고, Result 도구에 연결한 도구가 모두 Pass 일 때 그 스텝이 OK 입니다(§5.6).
예제 템플릿
자주 쓰는 도구 조합을 한 번에 놓아 주는 출발점(§5.8).
배치 테스트 · 골든셋
사진 폴더 전체로 레시피를 돌려 과검 · 미검을 세는 것. 골든셋은 정답(OK/NG)을 매겨 둔 기준 사진 묶음입니다(§5.11).
Web 파라미터 연동
도구의 기준값을 생산 관리 웹에서 바꿀 수 있게 이어 두는 것. 바꾸면 라인 PC 에 바로 전달됩니다(§5.7 · §8.10).
시퀀스 Process Sequence
AUTO RUN 중 "트리거 대기 → 촬영 → 검사 → 결과 출력 → 반복" 흐름을 노드로 그린 것(§5.10).
AUTO RUN
시퀀스대로 계속 검사하는 운전 상태. 시작 조건(작업지시 · 작업자 · 레시피)이 맞아야 시작됩니다(§4.3).
작업지시 · Lot Work Order
무엇을 몇 개 만들지 정한 지시와, 그 안에서 묶어 관리하는 생산 단위. 생산 관리 웹에서 만들고 VMS 에서 고릅니다(§4.3 · §8.7).
추적 정보 WO · Lot · S/N
검사 결과마다 붙는 작업지시 · Lot · 일련번호 등. 나중에 이력을 찾는 열쇠입니다(§4.3).
KPI
VMS 화면 위쪽의 생산 수 · 양품률 · 사이클 시간 같은 핵심 숫자(§4.4).
단독 모드
생산 관리 웹 없이 라인 PC 혼자 검사하는 운전. 작업지시 · 작업자 연동이 빠집니다(§4.9).
인스턴스
한 PC 에서 VMS 를 이름을 달리해 둘 이상 띄우는 것. 설정 · 레시피 · 이력이 따로 저장됩니다(§11.5).
IO 보드
PC 에 꽂는 디지털 입출력 카드. 센서 신호를 받고 램프 · 배출기를 켭니다(§3.7 · §5.10).
◆PLC
설비를 제어하는 산업용 컴퓨터. VMS 가 이더넷 · 시리얼로 직접 주소를 읽고 씁니다(§3.5). 더 읽기: 위키백과 — PLC
◆핸드셰이크 · 엔디언 Handshake · Endian
결과를 쓴 뒤 PLC 가 받았다는 신호를 확인하는 쓰기 방식, 그리고 여러 바이트 값의 순서. PLC 프로그램 규약과 맞춰야 합니다(§3.5).
점군 Point Cloud · .vpc
3D 카메라가 찍은 점 (X, Y, Z) 들의 모음. .vpc 는 VMS 가 저장한 점군 파일이고, 저장된 파일로는 기본 구성에서도 3D 검사를 만들 수 있습니다(§6.9 · §7.9). 더 읽기: Point cloud (Wikipedia)
높이 맵 Height Map · Depth Map
점군의 높이를 밝기로 바꾼 2D 사진. 2D 도구를 높이 정보에 쓸 수 있게 합니다(§5.13 · §6.10).
◆3D 카메라 촬영
3D 카메라(Mech-Mind)로 점군을 직접 찍는 기능. 저장된 .vpc 를 쓰는 기능과 달리 확장 옵션입니다(§3.4 · §5.13).
◆멀티뷰 스캔
로봇이 카메라를 여러 자세로 옮겨 가며 찍은 점군을 하나로 합치는 것. 한 번에 다 보이지 않는 큰 · 입체 부품에 씁니다(§5.13).
◆핸드아이 캘리브레이션 Hand-Eye
카메라 좌표와 로봇 좌표 사이의 관계(변환 행렬)를 구하는 것. 얼라인 보정량을 로봇 좌표로 바꾸고 멀티뷰 점군을 합치는 데 씁니다(§5.13). 더 읽기: Hand eye calibration problem (Wikipedia)
◆웨이포인트 스텝
로봇이 지나갈 촬영 자세마다 스텝을 하나씩 만든 것. 멀티뷰 스캔과 다점 검사에 씁니다(§5.13).
◆롤러 검사 Roller Inspection
라인스캔 카메라로 도는 롤러 표면을 연속 검사하는 운전 모드(§4.6).
확장 옵션 License Options
라이선스에 따로 들어 있어야 보이는 기능 묶음(◆). 본문에서 ◆ 로 표시했습니다(§1.6).
지문 코드 Fingerprint
PC 하드웨어로 만든 고유 코드. 라이선스는 이 코드에 묶여 발급됩니다(§2.6 · §13.7).
좌석 Seat
서버 라이선스 하나로 동시에 붙을 수 있는 라인 PC 수(§11.4 · §8.24).
보안 모드 Development · Production
Production 모드는 다른 PC 로 가는 http 주소를 막고 관리자 비밀번호를 요구하는 등 운영용으로 잠급니다(§3.8).
업로드 큐
서버에 닿지 못한 검사 결과를 라인 PC 에 파일로 쌓아 두었다가 연결이 돌아오면 다시 보내는 곳(§8.26).
Health Check
카메라 · 디스크 · 라이선스 · 서버 연결 등을 한 번에 점검하는 관리자 도구(§4.11).
지원 패키지 Support Package
문제 보고용으로 설정 · 로그 · 환경 정보를 묶은 ZIP. 레시피와 사용자 DB 는 넣지 않습니다(§4.11 · §11.7).
감사 로그 Audit Log
누가 언제 무엇을 바꿨는지 남는 기록(§4.11).
◆MLOps
딥러닝 모델을 만들고 · 배포하고 · 지켜보는 별도 서버(9장). 처음 쓰는 분을 위한 설명은 MLOps 매뉴얼 1부에 있습니다.
