9. ◆AI 학습 플랫폼 (BODA.VMS.MLOps)

◆ 확장 옵션 · 이 장은 요약입니다. MLOps 의 화면별 사용법과 개념(처음 쓰는 분용)은 별책 「BODA VMS MLOps 사용자 매뉴얼」에 있습니다. 아래 링크는 같은 폴더의 MLOps 매뉴얼 해당 절로 이어집니다. 여기에는 라인 PC(VMS) 쪽에서 알아야 할 것만 남겼습니다.

MLOps 는 딥러닝 검사 도구가 쓰는 모델(ONNX)을 만들고 라인에 배포하는 웹 서버입니다(기본 포트 5310). 라인 PC 와는 두 방향으로 이어집니다 — 불량 사진을 올리고(수집), 레시피가 가리키는 모델을 레시피를 불러올 때 받아 갑니다(배포). 설치는 §2.4 입니다.

9.1 로그인과 역할

Web 의 아이디 · 비밀번호로 들어오고, MLOps 안의 역할(Viewer · Labeler · Engineer · Admin)은 관리자가 [사용자 역할] 에서 붙입니다. → MLOps 매뉴얼: 접속과 로그인 · 역할과 권한 · 사용자 역할 지정

9.2 메뉴 구조

왼쪽 메뉴는 데이터 · 학습 · 배포 세 묶음입니다. 대시보드에 워커 · 모니터링 경고가 뜹니다. → MLOps 매뉴얼: 화면 구성과 대시보드

9.3 전체 흐름 — 수집에서 배포까지

수집 → 라벨링 → 판 뜨기 → 학습 → 평가 · 배포 → 모니터링의 한 바퀴. 처음이라면 MLOps 매뉴얼 1부(개념)부터 읽기를 권합니다. → MLOps 매뉴얼: MLOps 한 바퀴 · 작업 유형 고르기

9.4 수집 사진

라인 PC 가 보낸 NG 사진과 양품 샘플이 쌓이는 곳입니다. 라인 PC 쪽 설정은 §3.3(MLOps 주소 · 라인 토큰)과 §4.6(이미지 저장 설정의 NG 이미지 MLOps 전송)입니다. → MLOps 매뉴얼: 수집 사진 · 라인 PC 가 사진을 보내게 하기

9.5 데이터셋 · 라벨링

작업 유형과 클래스를 정해 데이터셋을 만들고, 사진에 라벨을 붙이고, 검토합니다. → MLOps 매뉴얼: 데이터셋 만들기 · 라벨링 화면 · 검토

9.6 학습 작업

판 · 모델 계열 · 스크립트 · 사전학습 가중치를 골라 제출하면 GPU 워커가 학습하고, 결과는 후보 버전으로 자동 등록됩니다. → MLOps 매뉴얼: 학습 제출 · 진행 · 곡선 · 재현성 · 실패 읽기

9.7 데이터셋 버전

학습은 언제나 그 순간을 굳힌 판으로 합니다. VisionSetup 의 OCR 합성 데이터(§5.12)도 판으로 올립니다(§10.1). → MLOps 매뉴얼: 판 만들기 · 올리기 · 무엇이 담기나

9.8 워커 · 사전학습 미러

학습을 돌리는 GPU PC(워커)와, 워커가 인터넷 대신 가중치를 받는 미러를 관리합니다. → MLOps 매뉴얼: 학습 준비 · 워커 등록 · 사전학습 미러

9.9 모델 레지스트리

모델 계열 · 버전 · 단계(후보 → 스테이징 → 운영)를 관리하고, 승격 전에 사진에 돌려 봅니다. → MLOps 매뉴얼: 모델 상세 · 돌려 보기 · 승격 · 강등 · 폐기 · ONNX 올리기

9.10 레시피 바인딩

라인 PC 는 레시피에 저장된 model:// 참조를 따릅니다. 참조는 VisionSetup 딥러닝 도구의 [레지스트리…](§5.13)에서 넣고, 라인의 VMS 는 레시피를 불러올 때 그 모델을 내려받아 둡니다(서버가 꺼져 있어도 받아 둔 모델을 씀). MLOps 의 [레시피 바인딩] 은 어떤 모델을 어느 레시피에 걸었는지 남기는 기록입니다 — 라인에 반영되는 것은 VisionSetup 에서 지정한 모델이며, 바인딩을 되돌려도(롤백) 기록만 바뀌고 라인 레시피는 그대로입니다. → MLOps 매뉴얼: 라인에 모델 걸기 · [레시피 바인딩] 화면

9.11 라인 PC

라인 PC 마다 계정을 만들어 라인 토큰(ln_…)을 받고, 설정 마법사 고급 설정(§3.3)에 넣습니다. → MLOps 매뉴얼: 라인 PC 계정 · 모델을 받아 가는 길

9.12 라인 모니터링

운영 웹의 검사 이력을 모델 버전별로 모아 불량률 · 신뢰도 · 입력 변화를 봅니다. VMS 가 결과에 모델 식별자를 실어 보냅니다. 결과가 쌓이려면 라인이 운영 Web 과 연동된 채 model:// 참조 레시피로 검사해야 하며, 그런 이력이 없으면 "아직 이어진 검사 결과가 없습니다" 만 보입니다. → MLOps 매뉴얼: 신호 읽기 · 재학습
