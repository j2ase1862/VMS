8. 생산 관리 웹 (BODA.VMS.Web)

이 장은 요약입니다. 생산 관리 웹의 화면별 사용법은 별책 「BODA.VMS.Web 사용자 매뉴얼」에 있습니다. 아래 각 절의 링크는 같은 폴더의 Web 매뉴얼 해당 절로 이어집니다. 여기에는 VMS 쪽에서 알아야 할 것만 남겼습니다.

BODA.VMS.Web 은 별도 프로그램 설치 없이 브라우저(Chrome)로 접속합니다. 주소창에 http://서버주소:5292 를 입력하세요 (라인 PC 안의 동봉 서버라면 http://localhost:5292). 설치는 §2.3, 라인 PC 와 이어 주는 설정은 §3.3 입니다.

8.1 로그인 · 회원가입 · 비밀번호

아이디 · 비밀번호로 들어오고, 새 계정은 회원가입 뒤 관리자 승인을 받아야 로그인됩니다. 임시 비밀번호는 첫 로그인에서 바꿉니다. → Web 매뉴얼: 접속과 로그인 · 회원가입 · 비밀번호 변경

8.2 메뉴 구조와 공통 동작

위쪽 메뉴 막대 여섯 묶음, 헤더 도구(시계 · 다크 모드 · 언어 · 알람 배지 · 사용자 메뉴), 표 · 검색 · 확인 창 같은 공통 동작. → Web 매뉴얼: 메뉴 · 헤더 도구 · 공통 동작

8.3 대시보드

오늘의 양품률 · 불량률 · 가동률과 라인별 상태를 한눈에 봅니다. 숫자의 계산식은 Web 매뉴얼 부록에 있습니다. → Web 매뉴얼: 대시보드

8.4 안돈 보드

현장 대형 화면용 라인 상태판입니다. 로그인 없이 띄울 수 있습니다. → Web 매뉴얼: 안돈 보드

8.5 알람

라인 오프라인 · 연속 불량 같은 알람을 확인하고, 조치를 적어 해제합니다. → Web 매뉴얼: 알람 확인 · 알람 해제

8.6 생산 이력

라인 PC 가 올린 검사 결과를 기간 · 라인 · 판정으로 찾고, 불량 상세(사진 · 측정값)와 Excel 내보내기를 씁니다. → Web 매뉴얼: 생산 이력 · Excel 내보내기

8.7 작업 지시

라인 · 제품 · 레시피 · 계획 수량으로 작업지시를 만들고 시작 · 완료 · 종료합니다. VMS 는 이 목록에서 작업지시를 고릅니다(§4.4). → Web 매뉴얼: 작업지시 등록 · 시작 · 완료 · 종료 · Lot

8.8 제품

제품 코드 · 이름 · 기본 레시피를 등록합니다. → Web 매뉴얼: 제품

8.9 작업자

작업자 사번 · 등급 · PIN 을 등록합니다. VMS 작업자 로그인(§4.3)과 키오스크가 이 명단을 씁니다. → Web 매뉴얼: 작업자 · 키오스크 · 출근 이력

8.10 레시피 파라미터 (검사 기준값)

VisionSetup 에서 Web 과 이은 파라미터(§5.7)의 기준값을 Web 에서 바꿉니다. 바꾸면 라인 PC 에 바로 전달됩니다. → Web 매뉴얼: 레시피 목록 · 프리셋 · 검사 항목과 상 · 하한

8.11 파레토 분석

불량 코드별 건수 · 비중 · 누적으로 어디부터 손댈지 봅니다. → Web 매뉴얼: 파레토 분석

8.12 SPC 관리도

측정값의 X̄-R 관리도와 공정 능력(Cp · Cpk)을 봅니다. → Web 매뉴얼: SPC 관리도

8.13 불량 코드

불량 코드를 등록하고, 라인이 올린 미등록 NG 코드를 코드로 만듭니다. → Web 매뉴얼: 불량 코드

8.14 교대 리포트

교대별 합격 · 불량 · 불량률을 봅니다. → Web 매뉴얼: 교대 리포트

8.15 PDF 리포트

기간 · 라인을 골라 품질 보고서를 PDF 로 받습니다. → Web 매뉴얼: PDF 리포트

8.16 비전 클라이언트 (라인)

라인 PC 를 라인 번호로 등록하고 IP · 상태 · 레시피 목록을 봅니다. 라인 번호는 설정 마법사의 Line Number(§3.3)와 같아야 합니다. → Web 매뉴얼: 비전 클라이언트

8.17 OEE 설비종합효율

라인 상태 기록으로 가용성 · 성능 · 품질 · OEE 를 계산합니다. → Web 매뉴얼: OEE

8.18 설비 신뢰성 (MTBF / MTTR)

고장 횟수와 평균 고장 간격 · 수리 시간을 봅니다. → Web 매뉴얼: 설비 신뢰성

8.19 예방 보전

점검 일정을 등록하고 수행 기록을 남깁니다. → Web 매뉴얼: 일정 등록 · 수행 기록

8.20 불량률 예측

예측 모델이 다음 1 시간의 라인별 불량률을 내다봅니다. VMS 헤더의 예측 칩(§4.4)도 이 값을 씁니다. → Web 매뉴얼: 불량률 예측 · 예측 모델 등록

8.21 교대 마스터 (Admin)

교대 이름과 시간대를 정합니다. → Web 매뉴얼: 교대 마스터

8.22 사용자 승인 (Admin)

가입 신청을 승인하고 역할 변경 · 비밀번호 초기화를 합니다. → Web 매뉴얼: 사용자 승인 · 역할과 권한

8.23 감사 로그 (Admin)

누가 언제 무엇을 바꿨는지 찾아봅니다. → Web 매뉴얼: 감사 로그

8.24 SW 라이선스 (Admin)

서버 라이선스 상태 · 좌석 · 서버 지문 코드를 봅니다. 지문 코드는 라이선스 발급 요청(§2.6)에 씁니다. → Web 매뉴얼: SW 라이선스

8.25 시스템 설정 (Admin)

서버 정보와 운영 설정을 봅니다. → Web 매뉴얼: 시스템 설정 · DB 백업 · 보존 설정

8.26 라인 PC 와 서버가 맞물리는 방식

단계무슨 일이 일어나는지
작업자 로그인VMS 가 사번 · PIN 을 서버로 보내면 서버가 작업자 명단과 대조해 세션을 만듭니다. 세션은 작업자 → 출근 이력 탭에 즉시 나타납니다.
작업지시 선택VMS 가 이 라인의 작업지시 목록을 받아 옵니다. 선택하면 레시피가 자동 로드되고 열린 Lot 이 채워집니다.
검사 결과 업로드사이클마다 결과(판정 · 측정값 · 추적 4 필드 · 검사 시각)가 올라가고, 서버는 작업지시 · Lot 수량을 올려 응답합니다. 헤더 진행률과 Web 작업 지시 화면이 즉시 갱신됩니다.
오프라인 복구서버에 닿지 못한 결과는 라인 PC 의 업로드 큐에 파일로 보관되었다가 연결이 돌아오면 순서대로 재전송됩니다. 재시작해도 남습니다. 같은 사이클이 두 번 도착해도 수량은 한 번만 오릅니다.
완료계획 수량 도달 시 서버가 완료 처리하고 라인 PC 에 알려 검사가 멈춥니다. Web 에서 수동 완료해도 같습니다.
생존 신호VMS 가 주기적으로 신호를 보냅니다. 15 초 이상 끊기면 라인이 오프라인으로 바뀌고 Offline 알람이 생기며 열린 작업자 세션이 자동 종료됩니다. 복구되면 알람은 자동 해제됩니다.

8.27 여러 라인 · 여러 서버 운영

  • 라인 PC 는 설정 마법사의 라인 번호(0~99)로 구분되며, 같은 서버 안에서 번호가 겹치면 안 됩니다. 작업지시 · 레시피 · 작업자 세션은 라인별로 분리됩니다.
  • 공장 네트워크 사정으로 서버를 여러 대 두고 라인을 나누어 붙일 수도 있습니다. 이때 라인 번호는 십의 자리를 서버 번호로 쓰기를 권장합니다 — 0~9 시험 · 예비, 10~19 1 번 서버, 20~29 2 번 서버 … 90~99 9 번 서버. 나중에 서버를 합치거나 보고서를 모을 때 어느 라인인지 구분됩니다.
  • 서버를 나누면 대시보드 · 작업지시 · 품질 분석 · 백업 · 관리자 계정 · 기준 정보도 서버마다 따로입니다. 네트워크가 허락하면 서버 1 대 구성이 운영이 가장 단순합니다.
  • 한 PC 에 카메라가 여러 대 있으면 VMS 를 인스턴스 이름으로 두 개 띄워 두 라인으로 운용할 수 있습니다(§11.5).

더 자세한 흐름은 Web 매뉴얼의 VMS 와 맞물리는 흐름 · 여러 서버 운영 에 있습니다.
