4. 검사 운전 (VMS 메인)

VMS 는 현장에서 매일 쓰는 메인 프로그램입니다. 이 장은 화면 구성을 먼저 익힌 뒤, 작업자가 검사를 시작하는 절차, 관리자가 쓰는 설정 · 이력 · 관리 도구 순서로 설명합니다.

빠른 시작 — 검사를 시작하는 가장 짧은 길
  1. 헤더의 Operator [Login...] 을 누르고 사번과 PIN 을 입력합니다.
  2. [Work Orders] 를 눌러 오늘 작업할 작업지시를 더블 클릭합니다.
  3. 레시피가 자동으로 불러와지고 [AUTO RUN] 이 켜집니다. 누르면 검사가 시작됩니다.
  4. 멈추려면 같은 자리의 빨간 [STOP] 을 누릅니다. 진행 상황은 헤더의 WO 칩(예: 5/100)과 KPI 카드에서 봅니다.

4.1 실행과 시작 화면

  1. 바탕화면의 BODA Vision System 바로가기를 실행합니다. 시작 화면(Splash)이 표시되는 동안 설정과 레시피를 읽고 카메라를 자동으로 연결합니다.
  2. 설정 파일이 없으면 "초기 시스템 설정이 필요합니다" 안내와 함께 시스템 설정 마법사(3장)가 열리고 VMS 는 종료됩니다. 마법사를 저장한 뒤 다시 실행하세요.
  3. 메인 화면이 뜹니다. 시스템 사용자 로그인 창은 시작 시 뜨지 않으며, 사이드 패널(⚙)을 열거나 헤더의 사용자 칩을 누를 때 표시됩니다(§4.12).
  4. 새 버전이 있으면 "업데이트 가능" 안내가 뜹니다(§2.7). 지금 검사를 해야 하면 닫고 나중에 진행해도 됩니다.

4.3 헤더 — 운영 흐름

헤더의 칩은 실제 작업 순서대로 왼쪽에서 오른쪽으로 배치되어 있습니다: 작업자 로그인 → 작업지시 선택 → 레시피 확인 → 검사 시작.

Operator 칩 — 작업자 로그인

  1. [Login...] 을 누르면 작업자 로그인 창이 열립니다. 사번과 PIN 을 넣고 [Login] (또는 Enter) 을 누릅니다.
  2. 입력값은 Web 서버의 작업자 명단과 대조됩니다. 성공하면 칩이 "이름 (사번)" 으로 바뀌고, 등급이 Lead(파랑) · Supervisor(빨강)면 뱃지가 붙습니다. Operator 등급은 뱃지가 없습니다.
  3. 실패 메시지가 "사번/PIN 오류" 가 아니라 "서버가 이 PC 의 키를 거부" 라면 설정 마법사의 Web Client API Key 를 확인합니다(§3.3).
  4. 교대 시에는 [Logout] 후 다음 작업자가 로그인합니다. VMS 를 정상 종료하면 서버의 작업자 세션도 함께 종료됩니다.

[Work Orders] — 작업지시 선택

  • 작업자 로그인 후 활성화됩니다. 누르면 Web 서버에서 이 라인에 배정된 작업지시 목록을 가져옵니다.
  • 상태 필터: 활성(Planned + InProgress, 기본) / 전체 / Planned / InProgress / Completed.
  • 행을 더블 클릭하거나 선택 후 [Select] 를 누릅니다. 선택하면 그 작업지시의 레시피가 자동으로 불러와지고, 열려 있는 Lot 이 하나면 Ctx 의 Lot 도 자동으로 채워집니다.

WO 칩 — 진행률

  • 검사 1 사이클이 끝날 때마다 진행 수량이 올라갑니다. 한 제품을 여러 스텝(카메라)으로 검사해도 1 사이클 = 제품 1 개로 집계됩니다.
  • 완료 기준이 "양품" 인 작업지시는 "양품 80 / 100" 처럼 합격 수량으로 표시됩니다(§8.7).
  • 여러 레시피가 섞인 작업지시는 칩에 마우스를 올리면 레시피별 진행이 줄 단위로 보입니다.
  • 계획 수량에 도달하면 검사가 자동으로 멈추고 작업지시 완료 창이 뜹니다 — 완료된 번호, 계획 · 검사 · Pass · NG 카드, 합격률이 표시되고 알림음이 울립니다. [다음 작업지시 선택] (Enter) 을 누르면 바로 Work Orders 창이 열립니다. Web 에서 관리자가 수동으로 완료해도 같은 창이 뜨며 검사가 즉시 멈춥니다.

Recipe 칩

현재 사용 중인 레시피 이름입니다. 작업지시를 선택하면 자동으로 바뀌며, PC 에 없는 레시피는 Web 서버에서 받아 온 뒤 다시 시도합니다. 검사가 도는 중에 VisionSetup 에서 이 레시피를 고쳐 저장하면 주황색 변경 대기 뱃지가 나타나고, 검사를 멈추는 순간 자동으로 다시 불러옵니다. 멈추기 전까지는 이전 설정으로 계속 검사합니다.

[AUTO RUN] / [STOP]

다음 조건을 모두 만족해야 켜집니다. 버튼이 꺼져 있으면 마우스를 올려 툴팁을 확인하세요.

  1. 카메라가 1 대 이상 연결되어 있음 (상태바 CAM 이 0/n 이 아님).
  2. 시스템 사용자로 로그인했다면 그 계정에 검사 시작/정지 권한이 있음 (로그인하지 않은 상태는 허용).
  3. (Web 연동 현장) 작업자가 로그인되어 있고, 작업지시가 선택되어 있으며 상태가 Planned 또는 InProgress 임.

AUTO RUN 을 시작하면 라이브 영상은 자동으로 멈추고, 시퀀스에 따라 트리거 대기 → 촬영 → 검사 → 판정 신호 출력이 반복됩니다. 카메라에서 이미지를 받지 못한 사이클은 검사 없이 NG 로 집계되므로 NG 가 연속으로 나오면 카메라 연결부터 확인하세요.

4.5 카메라 화면과 설정 창

카메라 타일의 헤더에는 연결 표시등(초록 Connected / 빨강 Disconnected), 카메라 이름, 설정(톱니바퀴) 버튼, 판정 배지가 있습니다. 본문은 2D · Depth Map · Point Cloud 탭이며 아래에 Run Results(도구별 Pass/Fail · 결과값 · 처리 ms) 표와 IP · Count 가 표시됩니다.

톱니바퀴를 누르면 타일 오른쪽에 카메라 조작 상자가 펼쳐집니다.

컨트롤설명
Step 콤보이 카메라가 쓰는 레시피 스텝을 고릅니다. 노출 · 게인은 스텝 단위로 저장됩니다.
카메라 설정 유지 (체크박스)기본 켬. 켜져 있으면 카메라에 저장된 노출/게인을 그대로 씁니다(제조사 프로그램에서 튜닝한 값 보존). 끄면 아래 값을 촬영 전에 카메라에 적용합니다.
Exposure (ms) / Gain (dB)노출 시간과 게인을 숫자로 입력합니다. "카메라 설정 유지"를 끄고 스텝을 고른 상태에서만 입력할 수 있습니다.
[Grab]사진을 한 장 촬영합니다. 카메라가 연결되어 있지 않으면 자동으로 연결합니다. 라이브 중에는 누를 수 없습니다.
[Live] / [Stop]모든 활성 카메라의 실시간 영상을 켜고 끕니다. AUTO RUN 을 시작하면 자동으로 꺼집니다.
[Open]이미지 파일을 열어 카메라 대신 표시합니다(카메라 없는 시험용).
[Inspect]현재 이미지로 검사를 1 회 실행합니다.
[Save Parameter]입력한 노출/게인을 스텝에 저장합니다. 완료/실패 메시지가 표시되며, 카메라가 등록되지 않았으면 설정 마법사를 먼저 실행하라는 안내가 뜹니다.
[Save 3D]촬영한 3D 데이터를 .vpc 파일로 저장합니다. VisionSetup 에서 열어 레시피를 만들 수 있습니다.
[Close]조작 상자를 닫습니다.
  • [Grab] · [Live] 가 눌리지 않으면 툴팁에 사유가 표시됩니다 — 시스템 사용자에게 시작/정지 권한이 없음, 작업자 로그인이 필요함, 연결된 카메라가 없음.
  • 운전이나 대기 중에 카메라 케이블이 빠지면 몇 초 안에 연결 표시등이 빨간색으로 바뀌고 상태바 CAM 수가 줄어듭니다. 다시 꽂으면 다음 촬영에서 자동으로 재연결됩니다. 라이브 표시는 연결이 끊기면 스스로 멈춥니다.
  • Basler 카메라도 스텝별 노출/게인이 그대로 적용되며, 연결 시 자동 노출/게인이 꺼져 촬영마다 밝기가 달라지지 않습니다.

4.6 사이드 패널 (Settings)

헤더 오른쪽 ⚙ 로 열고 닫습니다. 열 때 시스템 사용자 로그인이 필요하며, 패널 밖을 클릭하면 닫힙니다. 각 섹션 제목 옆의 물음표(?)를 누르면 설명이 표시됩니다.

Roller Inspection

라인 스캔 카메라로 회전하는 롤러 표면을 연속 검사하는 모드를 켜고 끕니다. AUTO RUN 조건을 만족하고 라인 스캔 카메라가 구성된 경우에만 켤 수 있습니다.

Recipe

  • 현재 레시피 이름과 버전, 사용할 수 있는 레시피 목록(수정일 포함)이 표시됩니다.
  • [Load] — 목록에서 고른 레시피를 불러옵니다. 단독 모드에서는 이 버튼으로 검사할 레시피를 정합니다.
  • [New] — "New Recipe" 이름의 빈 레시피를 만듭니다(레시피 편집 권한 필요). 도구 구성은 VisionSetup 에서 합니다.
  • ↻ — Web 서버의 레시피를 지금 가져옵니다(평소 60 초 주기 자동). 결과는 상태바에 "Web 레시피 3개 — 새 항목 1, 이름 연결 1" 처럼 요약되며, 0 개면 라인 번호가 맞는지 확인하라는 힌트가 붙습니다.
  • 저장 · 내보내기(JSON) · 가져오기 아이콘. 저장과 가져오기에는 레시피 편집 권한이 필요합니다.
VisionSetup 에서 지금 사용 중인 레시피를 고쳐 저장하면 실행 중인 VMS 가 자동으로 다시 불러옵니다(상태바 "외부 변경 반영 완료"). 검사 중이면 헤더 레시피 칩에 "변경 대기" 뱃지가 뜨고 정지 시점에 반영됩니다.

External Tools (Supervisor · Admin 전용)

  • [Vision Tool Setup] — 레시피 편집 프로그램(VMS.VisionSetup, 5장)을 실행합니다.
  • [System Setup] — 시스템 설정 마법사(3장)를 실행합니다.
  • 작업자 등급이 Operator · Lead 이면 이 섹션이 보이지 않습니다. 시스템 Admin 계정으로 로그인했거나 단독 모드에서는 항상 보입니다.

4.8 작업 절차 — 작업지시 선택부터 완료까지

  1. 출근 — [Login...] 에 사번 · PIN 을 입력합니다. 등급 뱃지가 맞는지 확인합니다.
  2. 작업지시 선택 — [Work Orders] 에서 오늘 지시를 더블 클릭합니다. 레시피 칩이 바뀌고 Ctx 의 WO 가 채워집니다.
  3. Lot 확인 — 열린 Lot 이 여러 개면 Ctx 의 Lot 콤보에서 지금 생산하는 묶음을 고릅니다. 묶음이 바뀔 때마다 바꿔 줍니다.
  4. 카메라 확인 — 필요하면 카메라 톱니바퀴 → [Grab] 으로 한 장 찍어 초점 · 밝기를 봅니다. 조정이 필요하면 "카메라 설정 유지"를 끄고 노출을 바꾼 뒤 [Save Parameter].
  5. 검사 시작 — [AUTO RUN]. 트리거(PLC/IO 신호)가 들어올 때마다 검사가 돌고 판정 배지 · KPI · WO 진행률이 갱신됩니다.
  6. 불량 확인 — NG History 썸네일을 눌러 어느 부위가 불량인지 봅니다. Run Results 표에서 어떤 도구가 Fail 인지 확인합니다.
  7. 완료 — 계획 수량에 도달하면 자동으로 멈추고 완료 창이 뜹니다. [다음 작업지시 선택] 으로 이어 갑니다.
  8. 퇴근 — [STOP] 후 [Logout]. VMS 를 끄면 서버의 세션도 정리됩니다.

4.9 단독 모드 — Web 서버 없이 운전

생산 이력 관리 없이 검사만 필요한 현장은 설정 마법사 2 단계에서 "Web 서버 미사용 — 단독(Standalone) 모드"를 체크합니다(§3.3). 단독 모드에서는 다음이 달라집니다.

  • 헤더의 Operator 칩 · [Work Orders] · WO 칩 · 예측 칩이 사라지고, 상태바 Web 칩이 "단독 모드 (Web 미사용)" 으로 표시됩니다.
  • 검사할 레시피는 사이드 패널 Recipe 섹션의 [Load] 로 고르고, 작업자 로그인 · 작업지시 없이 [AUTO RUN] 을 시작할 수 있습니다.
  • 검사 결과는 서버 대신 이 PC 의 검사 이력 파일에 사이클마다 저장됩니다(기본 90 일 보존). 최근 결과는 Recent Inspections 에서, 전체는 [전체 이력] 창(§4.10)에서 봅니다.
  • MLOps 주소 · 토큰을 넣어 두면 단독 모드에서도 NG 사진 수집과 모델 내려받기는 동작합니다.
  • External Tools 섹션은 등급과 무관하게 항상 보입니다.

나중에 서버를 두게 되면 마법사에서 체크를 해제하고 Web 서버 주소를 넣어 연동 모드로 바꿀 수 있습니다.

4.10 생산 이력 조회 창 — [전체 이력]

검사 결과는 사이클 또는 수동 검사 1 건마다 이 PC 의 검사 이력 파일(%LocalAppData%\BODA VISION AI\inspection_history.db)에 저장됩니다. 단독 모드의 영구 이력이며, Web 연동 현장에서는 오프라인 백업 역할을 합니다. 사이드 패널 Recent Inspections 의 [전체 이력] 로 엽니다.

  1. 필터를 고르고 [조회] 를 누릅니다 — From / To(기본 최근 7 일), 판정(전체 · PASS · NG), 레시피, NG 코드(실패 도구 이름 포함 검색). [필터 초기화] 로 되돌립니다.
  2. 이력 목록 탭 — 검사 시각 · 판정 · 레시피 · NG 코드/도구 · 구분(사이클/수동) · ms · 추적(시리얼 · 작업지시 · Lot) · IMG. 행을 누르면 오른쪽에 도구별 결과 표와 저장된 검사 사진이 표시되고 [폴더 열기] 로 파일 위치를 엽니다.
  3. 일별 집계 탭 — 기간 전체의 총 검사 · PASS · NG · 수율 카드와 날짜별 표.
  4. NG 파레토 탭 — NG 원인(NG 코드 또는 실패 도구)별 건수 · 비율 · 누적 비율.
  5. 200 건이 넘으면 하단 [◀ 이전] / [다음 ▶] 로 넘기고, [CSV 내보내기] 는 현재 필터의 전체 결과를 Excel 호환 CSV 로 저장합니다.
  • 검사 사진이 함께 보이려면 Image Saving 의 OK/NG 이미지 저장이 켜져 있어야 합니다. 보존 정리로 파일이 지워진 뒤에는 경로만 남습니다.
  • 보존 기간(기본 90 일)과 저장 켜기/끄기는 Admin Tools → Retention Settings 의 "검사 이력" 행에서 바꿉니다. 저장을 끄면 [전체 이력] 버튼이 비활성이 됩니다.
  • Web 연동 현장의 작업지시 · Lot 기준 전체 이력은 Web 의 생산 이력 화면(§8.6)이 기준입니다.

4.11 관리자 도구 (Admin 전용)

헤더의 User Management 아이콘과 Admin Tools(⋮) 메뉴에서 여는 창입니다. 시스템 Admin 계정으로 로그인했을 때만 보입니다.

User Management — 시스템 사용자 관리

  • Users 목록 — Username · Display Name · Grade · Last Login. 행을 선택하면 오른쪽 편집 패널에 값이 채워집니다.
  • Add New User — Username · Display Name · Password · Grade(Operator / Engineer / Admin) → [Add User].
  • Edit Selected User — Display Name · Grade 수정 → [Save Changes]. New Password → [Change Password]. [Delete User] 로 삭제.

Audit Log Viewer — 감사 로그

로그인 · 권한 거부 · 설정 변경 · 백업 등 관리 행위가 %LocalAppData%\BODA VISION AI\audit\YYYY-MM-DD.jsonl 에 기록됩니다. Outcome 은 Success(초록) · Failure(빨강) · Denied(주황)로 구분됩니다.

Health Check — 시스템 상태 점검

인스턴스 · 설정 파일 · 보안 옵션 · Web 서버 · 라이선스 · 디스크 여유 공간을 점검합니다. [Refresh] 로 다시 점검하고 [Copy] 로 결과를 복사해 지원 요청에 붙일 수 있습니다.

Backup / Restore — 백업과 복원

설정 파일 · 레이아웃 · PLC 신호 맵 · 사용자 DB · 검사 이력 DB · 레시피 전체(선택 시 감사 로그)를 ZIP 하나로 만듭니다. 복원 시 [기존 파일 덮어쓰기] 를 켜고 [Run Restore] 한 뒤 VMS 를 재시작합니다. 자세한 운영 요령은 §11.1 을 참고하세요.

Auto Backup Settings — 자동 백업

주기(1~720 시간)와 보존 기간(1~365 일), 저장 위치(비우면 backups 폴더)를 정합니다. 변경은 VMS 재시작 후 적용됩니다.

Retention Settings — 데이터 보존 정책

  • 빠른 프리셋 — Conservative(규제 사이트) / Standard(권장 기본) / Minimal(디스크 제한 사이트). 적용 후 [Save] 가 필요합니다.
  • 전역 보존(일) — 감사 로그 · 자동 백업 · 업로드 큐 · 검사 이력. "검사 결과를 로컬 이력 DB 에 저장" 체크로 로컬 이력 저장을 켜고 끕니다.
  • 카테고리별 차등 보존 — 9 개 감사 카테고리를 따로 지정합니다(기본: 보안/사용자/설정 1095 일, 인증/권한/레시피 730 일, 시퀀스/검사 365 일, 시스템 90 일).
  • [Preview] 는 실제 삭제 없이 정리 예정 건수를 보여 주고 [Export Preview...] 로 CSV 저장이 가능합니다. 변경은 VMS 재시작 후 적용됩니다.

Support Package — 원격 지원용 진단 패키지

문제 보고 시 공급사에 보낼 ZIP 을 만듭니다. 설정 파일 · 감사 로그(1~90 일) · 환경 정보 · 헬스 스냅샷 · MLOps 전송 큐 상태가 들어가며, 사용자 DB 와 레시피는 포함되지 않습니다.
