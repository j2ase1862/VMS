7. 검사 설정 예제

현장에서 자주 만드는 검사 유형별로 어떤 도구를 어떤 순서로 연결하고 무엇을 조정하는지를 단계별로 설명합니다. 모든 예제는 예제 템플릿 갤러리(§5.8)에서 한 번에 만들 수 있으며, 여기서는 만든 뒤 우리 제품에 맞게 손보는 요령까지 다룹니다. 공통 준비: VisionSetup 을 열고 레시피 · 스텝을 만든 뒤(§5.3) 기준 부품 이미지를 엽니다(§5.4).

7.1 부품 유무 · 개수 검사 (Blob)

상황 — 밝은 배경 위의 어두운 부품(또는 그 반대)이 정해진 개수만큼 있는지 확인합니다. 볼트 · 핀 · 오링 유무, 트레이의 부품 개수 세기에 씁니다.

  1. 템플릿 2D 측정 → Blob 검출 을 생성합니다.
  2. Threshold 를 선택하고 Run Selected 후 이미지 소스를 Result Image 로 바꿔 부품이 흰색, 배경이 검게 분리되는 Threshold Value 를 찾습니다. 조명이 고르지 않으면 Use Adaptive 를 켭니다.
  3. Blob 을 선택하고 Use ROI 를 켠 뒤 검사할 자리에 ROI 를 그립니다. Run 후 Run Results 의 Area 를 보고 Min/Max Area 를 부품 면적의 절반~두 배로 잡아 잡음을 거릅니다.
  4. 판정 — Enable Judgment 와 Use Count Judgment 를 켜고 Count Mode 를 Equal(정확히 N 개) 또는 Tolerance(기준 ± 공차)로, Expected Count 에 정상 개수를 넣습니다. 면적으로 크기까지 보려면 Use Area Judgment 도 켭니다.
  5. 양품 · 불량 이미지를 각각 열어 Run All 로 OK/NG 가 맞게 나오는지 확인하고 저장합니다. 이미지가 많으면 Batch Test(§5.11)로 한꺼번에 검증합니다.
부품이 트레이 안에서 조금씩 움직이면 앞에 Feature Match 를 두고 Coordinates 로 Blob 에 연결해 ROI 가 따라가게 합니다(§7.3).

7.2 치수 측정 — 엣지 간 거리 (Caliper + Geometry)

상황 — 부품의 폭 · 간격 · 높이를 mm 로 재고 공차로 판정합니다.

  1. mm 로 판정하려면 먼저 캘리브레이션(§5.9)을 하거나 Steps 표의 Resolution(mm/px)을 입력합니다.
  2. 템플릿 2D 측정 → 엣지 간 거리 측정 을 생성합니다.
  3. Caliper A 를 선택하고 첫 번째 엣지를 가로지르는 ROI 를 그립니다. Polarity(밝→어두 / 어두→밝)를 엣지 방향에 맞추고 Run 으로 엣지가 잡히는지 봅니다. Caliper B 도 같은 방법으로 두 번째 엣지에 둡니다.
  4. Geometry 의 Operation 은 PointPointDistance(두 점 거리)입니다. Enable Judgment 를 켜고 Unit=Mm, Expected Value 에 도면 치수, Tolerance ± 에 공차를 넣습니다.
  5. Run All 후 Run Results 의 DistanceMm 과 OK/NG 배지를 확인합니다. Web 에서 기준값을 관리하려면 Expected Value · Tolerance 옆 연동 콤보에 Dimension Tool 프리셋 코드를 연결합니다(§5.7).
엣지가 흔들리면 Caliper 의 Search Width 를 넓히고 Filter Half Width 를 키우거나, 앞에 Blur 를 둡니다. 직선 · 원 자체를 재려면 Line Fit · Circle Fit 을 Geometry 에 연결합니다(LineLineAngle, CircleCircleDistance 등).

7.3 위치 보정 후 검사 (Feature Match + Fixture)

상황 — 부품이 지그 안에서 조금씩 이동 · 회전합니다. 부품의 특징을 먼저 찾고, 그 위치를 기준으로 뒤 검사의 ROI 를 옮겨 늘 같은 자리를 검사합니다. 이렇게 기준을 잡아 주는 방식을 위치 보정(Fixture) 이라고 부릅니다.

  1. 템플릿 2D 측정 → 패턴 매칭 (Feature Match) 을 생성합니다(Grayscale → Feature Match → Result).
  2. Feature Match 를 선택하고 [Draw ROI] 로 부품의 뚜렷한 윤곽(모서리 · 구멍 · 마킹)을 감싸는 학습 영역을 그린 뒤 [Train Selected]. 오른쪽 특징 이미지의 초록 점이 윤곽을 따라 촘촘한지 확인합니다.
  3. Score Threshold 를 0.6~0.7 로 두고, 부품이 회전하는 범위만큼 Angle Start · Extent 를 잡습니다(아무 방향이면 −180 · 360). 다른 위치 · 각도의 이미지를 열어 Run 으로 매칭되는지 봅니다.
  4. 검사 도구(예: Blob · Caliper)를 추가하고 Feature Match 노드 우클릭 → Connect Coordinates → 검사 도구를 클릭합니다(파란 점선). 검사 도구의 ROI 를 기준 이미지에서 그립니다.
  5. 부품을 옮긴 이미지로 Run All 하면 검사 ROI 가 매칭 위치 · 각도를 따라 이동 · 회전한 것을 확인할 수 있습니다. 검사 도구와 Result 를 Result 로 연결해 최종 판정을 만듭니다.
  • 그림자 · 날짜 각인이 함께 학습되면 [Edit Mask...] 로 제외하거나 현장 이미지 2 장 이상으로 [안정 특징 정제] 를 씁니다.
  • 같은 부품이 여러 개면 Max Instances 를 올리고, 반쪽 매칭이 생기면 Min Coverage 0.6~0.75 를 켭니다.
Feature Match 가 부품을 못 찾으면 Coordinates 로 연결된 뒤 도구는 검사하지 않고 NG 가 됩니다. 최종 판정에 그 사유가 남도록 Feature Match 도 Result 로 판정 도구에 연결해 두세요.

7.4 색상 검사 — 컬러 라벨 · 부품 색 확인 (Color Extract + Blob)

상황 — 특정 색의 라벨 · 캡 · 케이블이 제자리에 있는지, 색이 맞는지 확인합니다.

  1. 템플릿 2D 측정 → 컬러 객체 검출 을 생성합니다. 컬러 이미지를 열어야 합니다(Grayscale 을 앞에 두지 마세요).
  2. Color Extract 를 선택하고 색 범위를 지정합니다 — 이미지에서 대상 색을 클릭해 값을 채우고(상태바에 BGR 값 표시) 허용 폭을 넓힙니다. Run 후 Result Image 로 대상 색만 흰색으로 남는지 확인합니다.
  3. Blob 에서 ROI · 면적 범위 · 개수 판정을 §7.1 과 같이 설정합니다.
  4. 색이 "맞는지" 만 보려면 Color Match 도구에 기준 색을 학습시키고 유사도 임계값으로 판정합니다(§6).

7.5 코드 판독 (Code Reader)

  1. 템플릿 식별 → 코드 판독 을 생성합니다.
  2. Code Reader 의 Code Reader Mode 를 코드 종류(1D 바코드 · 2D(QR · DataMatrix) · 자동)에 맞추고 ROI 를 코드 주변으로 그립니다. 작은 코드는 Try Harder 를 켭니다.
  3. 판독 문자열을 검증하려면 Enable Verification 을 켜고 Expected Text(또는 정규식)를 넣습니다. 인쇄 품질까지 보려면 Enable Quality Grading 과 Min Pass Grade 를 씁니다.
  4. Run 후 Run Results 의 Text 를 확인합니다. 곡면 라벨은 Circle Fit → Polar Unwrap 을 앞에 두어 펼친 뒤 읽습니다.

7.6 문자 인식 · 검증 (OCR / OCV)

  1. OCR 도구를 놓고 ROI 를 글자 영역에 그립니다. OCR Engine(Tesseract · PaddleOCR)과 Language 를 고르고, 숫자만 있는 각인은 Character Whitelist 에 0123456789 를 넣어 오인식을 줄입니다.
  2. 흐릿한 각인은 앞에 Image Enhance 를, 도트 프린트는 Dot Matrix Mode 를 켭니다. Auto Preprocess 는 기본 켬.
  3. "정해진 문자열이 맞는지" 만 보려면 OCV 도구에 기준 문자를 학습시켜 검증합니다. 날짜 · 로트처럼 형식이 정해진 문자열의 인식률을 높이려면 OCR Synth Data(§5.12)로 합성 데이터를 만들어 모델을 다듬습니다.

7.7 딥러닝 판정 — 검출 · 이상 탐지

상황 — 규칙으로 정의하기 어려운 외관 결함(긁힘 · 찍힘 · 이물)이나 다양한 모양의 부품을 학습된 모델로 판정합니다.

  1. 모델을 준비합니다 — MLOps(9장)에서 학습해 운영으로 승격하거나, AI 학습 도구(10장)로 ONNX 파일을 만듭니다.
  2. 템플릿 Deep Learning → DL 객체 검출 판정(또는 DL 이상 탐지 판정)을 생성합니다.
  3. Detection 의 Model Path 에 ONNX 파일을 지정하거나 [레지스트리…] 로 model://…@production 참조를 고릅니다. D-FINE · YOLO 형식은 자동 판별됩니다.
  4. Confidence Threshold(기본 0.5 부근)를 조정해 오검출과 미검출의 균형을 잡고, 특정 클래스만 볼 때는 클래스 필터를 씁니다. 0 건 검출은 NG 이므로 "결함이 없으면 OK" 인 검사에는 결과 해석을 Result 도구에서 반대로 잡습니다(결함 클래스 검출 = NG).
  5. 이상 탐지(Anomaly)는 정상 이미지만으로 학습한 모델을 쓰며 Anomaly Score 임계값으로 판정합니다. 히트맵 오버레이로 이상 부위를 확인합니다.
  6. GPU 가 없는 PC 는 CPU 로 동작합니다. 속도가 필요하면 Inference Settings(§5.12)에서 CUDA · TensorRT 를 고릅니다.

7.8 얼라인 — 로봇 · 스테이지 보정량 산출

상황 — 부품이 기준 위치에서 얼마나 이동 · 회전했는지 재서 로봇이나 서보에 보정량을 보냅니다(로봇 얼라인).

  1. 템플릿 얼라인 → Match Align — 2D 매치 얼라인 을 생성합니다. 각도 정밀도가 더 필요하면 부품 양단의 특징을 찾는 Feature Match 를 하나 더 붙여 Match Align 에 Result 로 연결하고 Mode 를 TwoPoint 로 바꿉니다(연결 순서 = 1 번 · 2 번 점).
  2. 기준(마스터) 부품을 놓고 Feature Match 를 학습합니다. 학습 위치가 곧 기준 포즈입니다.
  3. Match Align 에서 Unit=Mm(캘리브레이션 필요) · Max ΔXY · Max Δθ 를 정하고 Enable Judgment 를 켭니다. 로봇으로 보내려면 Enable Robot Transform 을 켜고 핸드아이 행렬 상위 2×2 를 넣습니다.
  4. 부품을 옮긴 이미지로 Run All → DeltaX · DeltaY · DeltaTheta(RobotDX · DY · DTheta)를 확인합니다. Match Align 의 PLC Output 에서 이 값들을 PLC 주소에 매핑하면 시퀀스가 돌 때마다 PLC 로 전달됩니다.
  5. 부품이 한 화면에 안 들어오면 2-스텝 얼라인(Multi-Step Align)을, 기울기까지 필요하면 3D 카메라로 평면 틸트 얼라인 · 2D+3D 하이브리드 얼라인 을 씁니다.

7.9 3D 검사 — 객체 개수 · 치수 · 형상 편차

상황 — 3D 카메라(Mech-Mind 등)로 찍은 점군에서 부품 개수와 가로 · 세로 · 높이를 재거나, 기준 형상과의 편차(들뜸 · 눌림)를 봅니다. "어디에 있는지" 는 2D 에서 찾고 "얼마나 큰지" 는 3D 에서 잽니다.

  1. 3D 카메라 스텝에서 Acquire(또는 3D → Load 3D Data 로 .vpc 파일)로 점군을 가져옵니다. Depth Map · Point Cloud 탭에서 확인합니다.
  2. 템플릿 3D → 3D 객체 카운트 · 치수 (기본) 를 생성합니다. Height Slicer 의 MinZ/MaxZ 를 부품 높이 범위(mm)로 맞추면 그 높이의 영역만 마스크가 됩니다. 딥러닝 윤곽으로 자르려면 DL 세그 기반 3D 객체 검출 을 씁니다.
  3. PointCloud Cluster 의 Tolerance(mm) 를 부품 사이 간격보다 작게, Min Points 를 잡음보다 크게 잡습니다. Scale Mode 는 AutoFromCamera(카메라 정보로 mm 자동 환산)를 권장합니다. Run 후 ClusterCount 와 Cluster{i}_SizeX/Y/Z 를 확인합니다.
  4. 형상 편차 검사는 3D 기준 형상 편차 검사 템플릿 — Registration 에 기준 점군(.vpc) 또는 CAD(.stl)를 지정해 자세를 맞춘 뒤 Deviation 의 Tolerance(mm) · Max Defect Ratio 로 판정합니다. 결과는 점군 위 히트맵(초록 = 일치, 빨강 = 초과)으로 표시됩니다.
  5. 점군 화면 위의 측정 툴바 [Distance] · [Angle] 로 점을 클릭해 즉석 측정할 수 있습니다.

7.10 레시피 마무리 — 시퀀스 · 배치 검증 · 운전 연결

  1. Result 도구를 스텝 끝에 두고 판정에 넣을 도구를 Result 로 연결합니다. 스텝이 여러 개인 레시피는 스텝마다 Result 를 둡니다.
  2. Batch Test(§5.11)로 양품 · 불량 이미지 폴더를 일괄 검사해 오판이 없는지 확인하고, 골든셋으로 저장해 두면 나중에 레시피를 고쳤을 때 회귀 확인이 됩니다.
  3. 시퀀스(§5.10)에서 트리거 입력 · 검사 · 분기 · 판정 출력 노드에 PLC 주소(또는 IO 채널)를 넣고 [무부하 테스트] 로 신호를 확인합니다.
  4. [Save Recipe] 로 저장합니다. Web 연동 현장은 Web 레시피 파라미터 화면에 같은 이름으로 자동 등록되며, 작업지시에 이 레시피를 지정하면 VMS 가 불러와 검사합니다(4장).
