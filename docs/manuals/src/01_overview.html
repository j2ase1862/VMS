1. 시스템 개요

BODA VMS(Vision Management System)는 산업용 카메라로 제품을 촬영해 양품/불량을 판정하는 머신 비전 검사 시스템입니다. 검사를 실제로 수행하는 검사 라인 PC, 여러 라인의 생산 실적과 품질을 한곳에서 관리하는 생산 관리 서버(BODA.VMS.Web), 그리고 딥러닝 검사 모델을 만들고 배포하는 AI 학습 플랫폼(BODA.VMS.MLOps, 선택)으로 구성됩니다. 이 매뉴얼은 설치 담당자, 검사 레시피를 만드는 엔지니어, 현장 작업자, 관리자가 각자 필요한 장을 찾아 볼 수 있도록 시스템 구성 → 설치 → 프로그램별 조작 → 검사 설정 → 웹 관리 → 유지보수 순서로 되어 있습니다.

1.1 시스템 구성

검사 라인 PC

라인마다 PC 1대를 두고, 카메라·PLC(또는 IO 보드)·필요 시 로봇을 연결합니다. 이 PC 에는 다음 프로그램이 함께 설치됩니다.

프로그램사용자역할
VMS (검사 운전)현장 작업자 · 반장 매일 쓰는 메인 화면입니다. 작업자 로그인 → 작업지시 선택 → [AUTO RUN] 으로 연속 검사를 돌리고, 판정 결과·수량·NG 이력을 보여 주며 검사 결과를 서버에 올립니다. PLC/IO 보드와 주고받는 트리거·판정 신호(시퀀스)도 이 프로그램이 처리합니다.
VMS.VisionSetup (레시피 편집)비전 엔지니어 검사 레시피를 만드는 작업 공간입니다. 39 종의 비전 도구를 끌어다 놓고 연결해 검사 순서를 만들고, 관심 영역(ROI)과 판정 기준을 정합니다. 시퀀스 편집기, 카메라 캘리브레이션, 배치 테스트, 예제 템플릿 갤러리가 여기에 있습니다.
VMS.AppSetup (시스템 설정 마법사)설치 담당자 카메라 · PLC · 로봇 · IO 보드 · Web/MLOps 서버 주소 · 보안 모드 · 라이선스를 7 단계 마법사로 설정합니다. 설치 후 최초 1 회 실행하며, 설비가 바뀔 때만 다시 엽니다.
VMS.DeepLearning (AI 학습 도구, 선택)비전 엔지니어 MLOps 서버 없이 이 PC 에서 직접 사진을 라벨링하고 모델을 학습할 때 쓰는 별도 프로그램입니다. 설치 시 "AI 학습 도구 포함"을 체크한 PC 에만 설치되며, 인증 범위 밖의 선택 구성 요소입니다. 사용법은 별책 「AI 학습 도구 매뉴얼」을 참고하세요.

생산 관리 서버 — BODA.VMS.Web

브라우저(Chrome)로 접속하는 웹 프로그램입니다. 작업지시 · Lot · 작업자 · 제품 · 불량 코드 같은 기준 정보를 관리하고, 라인에서 올라온 검사 결과로 생산 이력 · 알람 · 파레토 · SPC · OEE · 보고서를 만듭니다. VMS 설치 파일에 동봉되어 있어 라인 PC 와 같은 PC 에 Windows 서비스로 켤 수도 있고, 별도 서버 PC 에 설치해 라인 여러 대(최대 100 대)를 붙일 수도 있습니다. Web 서버 없이 검사만 하는 단독 모드도 지원합니다(§4.9).

AI 학습 플랫폼 — BODA.VMS.MLOps (선택)

딥러닝 검사 도구가 쓰는 모델(ONNX 파일)을 만드는 서버입니다. 라인에서 올라온 불량 사진을 모아 웹에서 라벨링하고, GPU 가 있는 학습 워커 PC 가 학습을 돌려 모델 레지스트리에 등록하면, 라인 PC 는 레시피의 참조(model://…)로 운영 모델을 자동으로 내려받습니다. MLOps 를 쓰지 않는 현장은 이 서버 없이 운영해도 됩니다.

1.2 운영 흐름 한눈에

설치와 레시피 작성이 끝난 뒤 현장에서 매일 반복되는 흐름은 다음과 같습니다.

  1. 관리자(Web)가 오늘의 작업지시(제품 × 수량 × 레시피)를 등록합니다. 필요하면 Lot 을 발행합니다.
  2. 작업자(VMS)가 헤더의 [Login...] 으로 사번과 PIN 을 입력해 로그인합니다.
  3. [Work Orders] 에서 작업지시를 고르면 레시피가 자동으로 불러와지고 [AUTO RUN] 이 켜집니다.
  4. [AUTO RUN] 을 누르면 시퀀스에 따라 트리거 대기 → 촬영 → 검사 → 판정 신호 출력이 반복됩니다.
  5. 검사 1 건마다 결과가 서버로 올라가고, 헤더의 진행 수량(예: 5/100)이 실시간으로 올라갑니다. 불량(NG)이 나오면 서버에 알람이 자동 생성됩니다.
  6. 계획 수량에 도달하면 작업지시가 자동으로 완료되고 완료 알림 창이 뜹니다. 다음 작업지시를 바로 고를 수 있습니다.
  7. 관리자(Web)는 대시보드 · 안돈 보드 · 생산 이력 · 품질 분석 화면에서 실적을 확인합니다.
단독 모드 현장은 1 · 2 · 3 · 7 단계가 없습니다. 레시피를 고른 뒤 바로 [AUTO RUN] 을 누르며, 검사 이력은 이 PC 의 생산 이력 조회 창(§4.10)에서 봅니다.

1.4 핵심 용어

용어설명
레시피 (Recipe)제품 하나를 검사하는 설정 묶음입니다. 카메라별 스텝, 스텝 안의 비전 도구 연결, ROI, 판정 기준을 담습니다. VisionSetup 에서 만들고 VMS 가 불러와 실행합니다. Web 에서는 "레시피 파라미터" 화면에서 기준값을 관리합니다.
스텝 (Step)레시피 안에서 카메라 1 대가 한 번 촬영해 검사하는 단위입니다. 이름은 "1-1", "1-2" 처럼 카메라 번호-순번으로 자동 매겨집니다.
도구 (Tool)이미지를 처리하거나 재고 판정하는 기능 블록입니다(Blob, Caliper, Feature Match 등 39 종, §6).
ROI도구가 볼 관심 영역입니다. 사각형 · 회전 사각형 · 원 · 타원 · 다각형으로 그립니다.
Fixture (좌표 연결)패턴 매칭이 찾은 위치·각도만큼 뒤 도구의 ROI 를 자동으로 옮기는 연결입니다. 제품이 조금씩 틀어져 놓여도 같은 자리를 검사합니다. 기준을 주는 도구가 제품을 못 찾으면 뒤 도구는 실행되지 않고 NG 로 처리됩니다.
시퀀스AUTO RUN 중 "트리거 대기 → 촬영 → 검사 → 결과 출력 → 반복" 흐름의 정의입니다. PLC 주소나 IO 보드 채널을 노드로 연결합니다.
작업지시 (WO)제품 × 계획 수량 × 레시피 단위의 생산 지시입니다. 계획됨 → 진행 중 → 완료 → 마감 순서로 진행됩니다.
Lot작업지시 안에서 자재 투입분이나 교대 단위로 나누는 생산 묶음입니다. 한 작업지시에 여러 Lot 을 동시에 열 수 있습니다.
작업자 (Operator)사번 + PIN 으로 VMS 나 키오스크에서 출근하는 현장 인력입니다. 등급은 Operator / Lead / Supervisor.
시스템 사용자VMS PC 안의 관리 계정(Operator / Engineer / Admin)입니다. 설정 패널 · 레시피 편집 · 관리자 도구 권한을 정합니다(§4.12).
OK / NG검사 판정 결과입니다. NG 가 나오면 Web 에 알람이 자동 생성됩니다.
라인 번호 (ClientIndex)Web 서버가 라인 PC 를 구분하는 번호(0~99)입니다. 작업지시 · 레시피 · 이력이 이 번호로 분리됩니다.
model:// 참조딥러닝 도구의 모델 파일 대신 MLOps 레지스트리의 모델을 가리키는 주소입니다. 예: model://{모델ID}@production

화면의 버튼 이름은 [대괄호]로, 메뉴 경로는 메뉴 → 항목 으로 적었습니다. 입력란 옆의 파란 물음표(?) 아이콘에 마우스를 올리면 그 항목의 설명이 프로그램 안에서 바로 표시되므로, 설정 중에 매뉴얼을 뒤지지 않아도 됩니다.
