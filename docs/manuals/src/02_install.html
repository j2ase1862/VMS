2. 설치

⚙ 이 장은 설치 담당자 · 관리자용입니다. 현장에서 검사만 수행하는 작업자는 4장부터 읽으면 됩니다.

2.1 설치 전 준비

설치 파일(MSI) 하나에 VMS · VisionSetup · AppSetup · Web 서버 · .NET 런타임 · Visual C++ 런타임이 모두 들어 있습니다. 인터넷이 안 되는 공장 PC 에서도 다른 프로그램을 먼저 설치할 필요가 없습니다. 다만 카메라 · IO 보드 제조사 소프트웨어는 장비에 따라 별도로 설치해야 합니다.

장비별도 설치할 것비고
Basler 카메라pylon Camera Software Suite (Runtime)없으면 카메라 검색은 되지만 연결 · 촬영이 실패합니다
ADLink IO 보드DASK 드라이버 64비트(x64)32비트만 설치된 PC 에서는 보드가 인식되지 않습니다
Advantech IO 보드DAQNavi미설치 시 보드가 연결되지 않습니다(System Log 에 사유)
실제 카메라로 연결되는 제조사는 위 표의 Basler 입니다. 설정 마법사의 제조사 목록에 있는 그 밖의 제조사를 고르면 카메라가 시뮬레이션 모드로 동작합니다 — 화면에 보이는 영상은 실제 카메라 영상이 아닙니다. VisionSetup 에서 연결할 때 "SDK 미탑재 — 시뮬레이션 모드" 경고 창이 뜹니다. 카메라 없이 시험할 때는 제조사를 Virtual 로 둡니다(경고 창 없이 시뮬레이션 영상으로 동작).

설치 순서 (권장)

  1. 카메라 · IO 보드를 PC 에 연결하고 제조사 소프트웨어를 설치합니다.
  2. VMS 설치 파일을 실행합니다 (§2.2).
  3. 서버 PC 를 따로 두는 구성이면 서버 PC 에 Web 서버를 먼저 설치하고 접속을 확인합니다 (§2.3).
  4. 이 PC 에 라이선스 파일을 설치하는 구성이면, 시스템 설정 마법사(3장)의 마지막 단계에서 지문 코드를 확인해 기본 구성 라이선스를 발급받고 가져옵니다 (§2.5). 라이선스를 먼저 넣어야 마법사가 이 매뉴얼과 같은 5 단계로 표시됩니다.
  5. 라인 PC 에서 시스템 설정 마법사(3장)를 실행해 카메라 · IO 보드 · Web 주소 · 보안 모드를 저장합니다.
  6. VMS 를 실행해 하단 상태바의 CAM · Web 연결 표시를 확인합니다 (§4.7).

2.2 VMS 설치 (설치 마법사)

  1. VMS-1.48.1.msi 처럼 버전이 붙은 설치 파일을 더블 클릭합니다. 설치에는 관리자 권한이 필요합니다.
  2. 시작 화면에서 [다음]을 누릅니다. 별도의 라이선스 동의 단계는 없습니다.
  3. 설치 폴더는 설치 마법사가 보여 주는 기본값을 그대로 두는 것을 권장합니다.
  4. 설치 구성 선택 화면에서 이 PC 에 함께 설치할 항목을 고릅니다.
    • BODA VMS Web 서버 포함 (권장, 기본값) (기본: 켬) — 이 PC 를 생산 관리 서버로도 쓰거나, 나중에 쓸 가능성이 있으면 켜 둡니다. 포함해서 설치해도 자동으로 실행되지는 않으며, 설정 마법사에서 켤 때만 동작합니다(§2.3).
    • 체크를 해제하면 웹 서버 파일이 설치되지 않으며, 업데이트해도 그 구성이 유지됩니다. 나중에 웹 서버를 넣으려면 프로그램을 제거한 뒤 다시 설치하면서 체크합니다(설정 · 레시피 · 검사 이력은 제거해도 남습니다, §2.6).
  5. [설치]를 누르면 파일 복사가 진행되고, 완료 화면에서 [마침]을 누릅니다. 바탕화면에 BODA VMS 바로가기가, 시작 메뉴의 VASIM 폴더에 BODA VMS · BODA VMS 설정 마법사 (AppSetup) · BODA VMS 비전 설정 (VisionSetup) 바로가기가 만들어집니다. Web 서버를 포함해 설치하면 Windows 방화벽에 인바운드 규칙 BODA VMS Web (5292/TCP) 도 함께 만들어집니다(§2.4).
무인 설치가 필요하면 명령 프롬프트(관리자)에서 다음처럼 실행합니다. msiexec /i VMS-1.48.1.msi /qn INSTALLWEB=0 — 값 0 은 제외, 1 은 포함입니다.

설치 후 처음 실행하면

VMS 를 처음 실행하면 설정 파일이 없으므로 "초기 시스템 설정이 필요합니다" 안내와 함께 시스템 설정 마법사(VMS.AppSetup)가 자동으로 열립니다. 3장에 따라 마지막 단계까지 저장한 뒤 VMS 를 다시 실행하세요. 마법사는 기본 구성 라이선스가 설치된 PC 에서 5 단계이며, 라이선스를 넣기 전에는 단계가 더 보입니다(§3.1). 설정 파일이 있어도 마법사를 끝까지 저장하지 않은 것이면 "시스템 설정이 끝나지 않았습니다" 안내와 함께 마법사가 열립니다. 설정 파일과 레시피, 검사 이력은 모두 %LocalAppData%\BODA VISION AI\ 아래에 저장되며 프로그램을 제거하거나 업그레이드해도 지워지지 않습니다.

2.3 Web 서버 설치와 구성

생산 관리 웹(BODA.VMS.Web)은 Windows 서비스 BodaVmsWeb 으로 실행되며 포트 5292 를 씁니다. 별도의 웹 서버 프로그램(IIS 등)이나 데이터베이스 설치는 필요 없습니다(SQLite 내장). 구성은 두 가지입니다.

방법 A — 라인 PC 에 동봉된 Web 서버 켜기 (설정 마법사)

설치 구성 선택에서 "Web 서버 포함"을 켠 PC 에서는 명령어 없이 화면에서 켤 수 있습니다.

  1. 시스템 설정 마법사(3장)를 실행해 2 단계 Application Settings 로 이동합니다.
  2. "Web 서버 초기 구성 (이 PC)" 카드의 Web Admin 비밀번호 와 비밀번호 확인 에 관리자(admin) 계정 비밀번호를 똑같이 입력하고 [초기 구성 실행 (관리자 권한)] 을 누릅니다. 비밀번호는 8 자 이상이어야 하며 12 자 이상을 권장합니다. Windows 권한 확인 창(UAC)이 뜨면 승인합니다.
  3. 설정 작성 → 부팅 시 자동 시작 전환 → 서비스 시작 → 응답 확인이 자동으로 진행되고(서비스 등록은 설치 파일이 미리 해 둡니다), "Web 서버 구성 완료" 안내 창이 뜹니다. 카드에는 "✔ 초기 구성 완료" 와 서비스 상태 "서비스 실행 중 (Running)" 이 표시됩니다. 이 구성은 버튼을 누르는 즉시 적용되며 마법사의 [Finish] 를 기다리지 않습니다.
  4. 같은 페이지의 Web Server URL 이 http://localhost:5292 인지 확인하고 마법사를 끝까지 진행해 저장합니다.
  5. 브라우저에서 http://localhost:5292 에 접속해 로그인 화면이 뜨면 완료입니다. 계정은 admin / 방금 입력한 비밀번호입니다.
  • 구성은 끝났는데 서비스가 멈춰 있으면(Stopped) 카드에 [서비스 시작 (관리자 권한)] 버튼이 나타납니다. 누르면 Windows 권한 확인 창(UAC)이 뜨고, 승인하면 서비스가 부팅 시 자동 시작으로 바뀐 뒤 곧바로 시작됩니다.
  • 이 구성의 Web 서버는 이 PC 의 모든 네트워크 주소(포트 5292)에서 응답하고, 설치 때 만들어진 방화벽 규칙 BODA VMS Web (5292/TCP) 이 열려 있습니다. 그래서 같은 네트워크의 다른 PC 브라우저 · 다른 라인 PC 에서도 http://이 PC 의 IP:5292 로 접속됩니다. 추가 설정은 필요 없습니다(§2.4).

방법 B — 별도 서버 PC 에 설치 (배포 스크립트)

라인이 여러 대이거나 사무실에서 항상 접속해야 하면 서버 PC 를 따로 둡니다. Web 서버 배포 패키지는 설치 매체에 MSI 와 함께 제공되며(없으면 공급사에 요청), 관리자 PowerShell 에서 다음을 실행합니다.

# 관리자 PowerShell — 압축을 푼 폴더로 이동
cd <압축 푼 폴더>\deploy
.\Install-Web-Offline.ps1 -AllowLanAccess

스크립트가 서비스 등록 · 서명 키 생성 · 초기 관리자 비밀번호 생성 · 설정 파일 권한 제한 · 방화벽 규칙까지 한 번에 처리하고, 화면에 초기 admin 비밀번호를 표시합니다. 기본값은 설치 폴더 C:\Deploy\BodaVmsWeb, 데이터 폴더 C:\ProgramData\BODA\VMS, 포트 5292 입니다. 옵션으로 바꿀 수 있습니다.

.\Install-Web-Offline.ps1 -AllowLanAccess -Port 8080 -InstallPath "D:\BODA Web" -DataDir "D:\BODA Data"
다른 PC 에서 접속하는 서버는 반드시 -AllowLanAccess 를 붙여 설치합니다. 이 옵션을 붙이면 서버가 모든 네트워크 주소에서 응답하고, 방화벽 인바운드 규칙 BODA VMS Web (5292/TCP) 을 사내망(Domain · Private) 프로필에 만들며, 완료 화면에 "LAN 접속" 주소가 표시됩니다(포트를 바꾸면 규칙 이름의 숫자도 그 포트가 됩니다). 옵션 없이 설치하면 서버가 이 PC 안에서만(127.0.0.1) 응답하고 방화벽 규칙을 만들지 않아 라인 PC 와 다른 PC 의 브라우저에서 접속되지 않으며, 완료 화면에 "LAN 접속 : 꺼짐 — 이 PC 에서만 접속됩니다" 가 표시됩니다. 이때는 -AllowLanAccess 를 붙여 다시 실행합니다(설정과 데이터는 유지됩니다).
서명 키의 유일한 사본은 서버의 appsettings.Production.json 입니다. 이 파일을 잃으면 모든 사용자가 다시 로그인해야 하므로 설치 직후 안전한 곳에 백업하세요. 첫 로그인 후에는 admin 비밀번호를 바꾸고(오른쪽 위 사용자 이름 → [비밀번호 변경], §8.1), 필요한 사용자를 가입 → 승인으로 추가합니다(가입 §8.1 · 승인 §8.22).

2.4 네트워크 · 방화벽

연결포트 / 프로토콜방향용도
라인 PC → Web 서버5292 / TCP (HTTP)아웃바운드검사 결과 업로드 · 작업지시 · 작업자 로그인 · 실시간 알림(SignalR)
브라우저 → Web 서버5292 / TCP인바운드(서버)관리 화면 접속
라인 PC ↔ 카메라3956 / UDP + GVSP 스트림양방향GigE Vision 검색 · 영상 수신 (점보 프레임 9000 권장)
  • 별도 서버 PC(방법 B)는 배포 스크립트를 -AllowLanAccess 로 실행했을 때 모든 네트워크 주소에서 응답하고, 방화벽 인바운드 규칙 BODA VMS Web (5292/TCP) 이 사내망(Domain · Private) 프로필에 만들어집니다. 옵션 없이 설치하면 그 PC 안에서만 응답하고 규칙도 만들어지지 않습니다(§2.3).
  • 라인 PC 의 동봉 구성(방법 A)은 설치할 때부터 모든 네트워크 주소(5292)에서 응답하고, 설치 파일이 방화벽 인바운드 규칙 BODA VMS Web (5292/TCP) 을 모든 네트워크 프로필에 만듭니다. 다른 PC 에서 접속하기 위한 추가 설정은 필요 없습니다. 다른 PC 에서 접속할 필요가 없는 현장은 Windows 방화벽 고급 설정에서 이 규칙의 프로필을 줄이거나 규칙을 끕니다. 이 규칙은 프로그램을 제거하면 함께 지워집니다.
  • 카메라는 전용 네트워크 카드에 직결하고, 그 카드에만 카메라와 같은 대역의 고정 IP 를 줍니다.
  • 보안 모드가 Production 인 라인 PC 는 다른 PC 를 가리키는 http:// 서버 주소를 거부합니다(§3.6). 동봉 구성(방법 A)과 배포 스크립트(방법 B)는 Web 서버를 http:// 로만 엽니다. 그래서 Production 모드의 라인 PC 를 다른 PC 의 서버에 붙이려면 서버를 https:// 로 따로 열어야 하며(인증서를 준비해 서버 설정에 지정 — 공급사에 문의), 사내 실증 단계에서는 Development 모드를 씁니다. 같은 PC 를 가리키는 localhost 주소는 http 여도 허용됩니다.

2.5 SW 라이선스 설치 · 활성화

SW 라이선스는 "이 PC 에서 BODA VMS 를 사용해도 된다"는 사용권 파일(license.lic)입니다. 인터넷 연결 없이 파일 하나로 동작하므로 폐쇄망에서도 추가 설정이 필요 없습니다. 지금은 도입 전환기라 라이선스가 없어도 사용 제한은 없으며, 상태 표시와 기록에 "미설치" 경고만 남습니다. 다만 라이선스 파일이 없는 PC 에서는 라이선스에 따라 숨겨지는 확장 옵션 화면까지 모두 표시됩니다(예: 설정 마법사가 5 단계가 아니라 7 단계). 이 매뉴얼은 기본 구성 라이선스를 설치한 상태를 기준으로 설명하므로, 설정을 시작하기 전에 라이선스를 먼저 설치하세요.

지문 코드로 발급받기

  1. 시스템 설정 마법사를 열고 [Next] 로 마지막 페이지(Security & License)까지 이동합니다. 라이선스를 넣기 전이라 중간에 PLC Communication · Robot Configuration 단계가 보이면 값을 바꾸지 않고 [Next] 로 넘어갑니다. SW 라이선스 카드에서 지문 코드(예: 0X0Y9-MMS36-7540K, 15 자)를 [복사]해 본사 담당자에게 전달합니다. 전화 · 메신저 · 이메일 모두 가능합니다. 라이선스를 기다리는 동안 마법사는 닫아도 됩니다.
  2. 발급받은 license.lic 파일을 USB 등으로 이 PC 에 옮깁니다. 파일은 이 PC 에서만 유효합니다.
  3. [라이선스 파일 가져오기...] 를 누르고 파일을 선택합니다. 권한 확인 창(UAC)이 뜨면 [예]를 누릅니다.
  4. 카드의 현재 상태가 정상으로, 확장 옵션이 기본 구성 (확장 옵션 없음) 으로 바뀌면 완료입니다. 라이선스는 가져오는 즉시 설치되며([Finish] 를 기다리지 않습니다), 마법사의 단계 표시가 그 자리에서 5 단계로 바뀝니다. 이어서 [← Back] 으로 2 단계로 돌아가 3장의 순서대로 설정합니다.

서버 1 대 + 라인 여러 대 구성

Web 서버가 있는 구성이라면 라이선스는 서버 PC 에만 설치합니다. 각 라인 PC 는 서버에서 자동으로 사용권(좌석)을 받아 가며, 라인 PC 를 교체해도 재발급이 필요 없습니다. 좌석 현황은 Web 시스템 관리 → SW 라이선스에서 봅니다(§8.24). 서버가 꺼져 있어도 라인 PC 는 마지막으로 좌석을 받은 시점부터 72 시간 동안 정상 동작합니다. 라이선스 파일을 두지 않은 라인 PC 의 설정 마법사는 현재 상태가 "미설치" 로, 단계가 7 단계로 표시됩니다 — 이 매뉴얼에 없는 단계는 값을 바꾸지 않고 [Next] 로 넘어갑니다(§3.1).

재발급이 필요한 경우

  • 지문 불일치 — 다른 PC 용 라이선스이거나, PC 를 바꾸는 등으로 지문 코드의 세 묶음 중 두 묶음 이상이 달라진 경우입니다(한 묶음만 달라지면 그대로 유효합니다). 새 지문 코드로 재발급을 요청합니다.
  • 만료 임박 · 유지보수 만료 — 계약 갱신 후 받은 새 파일을 같은 방법으로 가져오기 하면 덮어써집니다.

2.6 업그레이드와 제거

인앱 업데이트 (권장)

새 버전이 나오면 VMS 가 시작할 때 창을 띄우지 않고 알려 줍니다 — 사이드 패널 Updates 섹션에 배지가 표시되고, System Log 에 "새 버전 감지" 줄이 남습니다.

  1. 사이드 패널 Updates 의 배지나 [Check for updates] 를 누르면 "업데이트 가능" 창이 열립니다. 창에서 [예]를 누릅니다.
  2. 설치 파일이 앱 안에서 다운로드되며 Updates 섹션에 진행률이 표시됩니다. [다운로드 취소]로 멈출 수 있고, 내려받은 파일은 손상 여부(SHA-256)를 자동 검증합니다.
  3. 다운로드가 끝나면 설치 시작 확인 창이 뜹니다. 시작하면 Windows 권한 확인 창(UAC)이 한 번 뜨고, 진행률 창(버전 · 현재 작업 · %)이 표시되는 동안 기다립니다.
  4. 설치가 끝나면 VMS 가 자동으로 다시 실행됩니다. 이 PC 에서 Web 서비스를 운영 중이었다면 업데이트가 서비스를 먼저 내리고, 설치 후 다시 시작해 응답까지 확인합니다.
  • 자동 검사(AUTO RUN)가 도는 동안에는 업데이트를 시작할 수 없습니다. 검사를 멈춘 뒤 진행하세요.
  • 다운로드나 설치가 실패하면 브라우저에서 설치 파일을 직접 내려받는 방법이 안내됩니다. 설치 과정 기록은 C:\ProgramData\BODA\VMS\update-bootstrap.log 에 남습니다.

설치 파일로 직접 업그레이드

새 버전 MSI 를 더블 클릭하면 이전 버전이 자동으로 제거되고 새 버전이 설치됩니다. 설치 구성(Web 서버 포함 여부)은 이전 설치를 따릅니다 — 설치 구성 선택 화면의 체크가 이전 설치와 같은 상태로 나오고, 인앱 업데이트도 이전 구성을 그대로 유지합니다(Web 서버를 빼고 설치한 PC 는 계속 빠지고, 넣은 PC 는 계속 들어갑니다). 설정 · 레시피 · 검사 이력 · 캘리브레이션은 그대로 보존됩니다.

제거

  • Windows 설정 → 앱 → "BODA VMS" → 제거. 시작 메뉴에는 제거 바로가기가 없으므로 이 경로로 제거합니다. 프로그램 파일, 바탕화면 · 시작 메뉴(VASIM 폴더) 바로가기와, Web 서버를 포함해 설치한 PC 는 Web 파일 · BodaVmsWeb 서비스 · 방화벽 규칙 BODA VMS Web (5292/TCP) 이 지워집니다.
  • 사용자 데이터(%LocalAppData%\BODA VISION AI\)와 Web 데이터(C:\ProgramData\BODA\VMS\)는 제거해도 남습니다. 완전히 지우려면 두 폴더를 직접 삭제합니다.
