2. 설치

⚙ 이 장은 설치 담당자 · 관리자용입니다. 현장에서 검사만 수행하는 작업자는 4장부터 읽으면 됩니다.

2.1 설치 전 준비

설치 파일(MSI) 하나에 VMS · VisionSetup · AppSetup · Web 서버 · .NET 런타임 · Visual C++ 런타임이 모두 들어 있습니다. 인터넷이 안 되는 공장 PC 에서도 다른 프로그램을 먼저 설치할 필요가 없습니다. 다만 카메라 · IO 보드 제조사 소프트웨어는 장비에 따라 별도로 설치해야 합니다.

설치 순서 (권장)

  1. 카메라 · PLC · IO 보드를 PC 에 연결하고 제조사 소프트웨어를 설치합니다.
  2. VMS 설치 파일을 실행합니다 (§2.2).
  3. 서버 PC 를 따로 두는 구성이면 서버 PC 에 Web 서버를 먼저 설치하고 접속을 확인합니다 (§2.3).
  4. 라인 PC 에서 시스템 설정 마법사(3장)를 실행해 카메라 · PLC · Web 주소 · 보안 모드를 저장합니다.
  5. VMS 를 실행해 하단 상태바의 CAM · Web 연결 표시를 확인합니다 (§4.7).

2.2 VMS 설치 (설치 마법사)

  1. VMS-1.39.2.msi 처럼 버전이 붙은 설치 파일을 더블 클릭합니다. 설치에는 관리자 권한이 필요합니다.
  2. 시작 화면에서 [다음]을 누릅니다. 별도의 라이선스 동의 단계는 없습니다.
  3. 설치 폴더는 기본값 C:\Program Files\VASIM\BODA Vision System\ 을 그대로 두는 것을 권장합니다.
  4. 설치 구성 선택 화면에서 이 PC 에 함께 설치할 항목을 고릅니다.
    • BODA VMS Web 서버 포함 (기본: 켬) — 이 PC 를 생산 관리 서버로도 쓰거나, 나중에 쓸 가능성이 있으면 켜 둡니다. 포함해서 설치해도 자동으로 실행되지는 않으며, 설정 마법사에서 켤 때만 동작합니다(§2.3).
    • AI 학습 도구 포함 (기본: 해제) — MLOps 서버 없이 이 PC 에서 직접 모델을 학습해야 하는 엔지니어 PC 만 켭니다. 검사만 하는 라인 PC 에는 필요 없습니다.
  5. [설치]를 누르면 파일 복사가 진행되고, 완료 화면에서 [마침]을 누릅니다. 시작 메뉴와 바탕화면에 바로가기가 만들어집니다.
무인 설치가 필요하면 명령 프롬프트(관리자)에서 다음처럼 실행합니다. msiexec /i VMS-1.39.2.msi /qn INSTALLWEB=0 INSTALLAITOOLS=0 — 값 0 은 제외, 1 은 포함입니다.

설치 후 처음 실행하면

VMS 를 처음 실행하면 설정 파일이 없으므로 "초기 시스템 설정이 필요합니다" 안내와 함께 시스템 설정 마법사(VMS.AppSetup)가 자동으로 열립니다. 3장에 따라 7 단계를 저장한 뒤 VMS 를 다시 실행하세요. 설정 파일과 레시피, 검사 이력은 모두 %LocalAppData%\BODA VISION AI\ 아래에 저장되며 프로그램을 제거하거나 업그레이드해도 지워지지 않습니다.

2.3 Web 서버 설치와 구성

생산 관리 웹(BODA.VMS.Web)은 Windows 서비스 BodaVmsWeb 으로 실행되며 포트 5292 를 씁니다. 별도의 웹 서버 프로그램(IIS 등)이나 데이터베이스 설치는 필요 없습니다(SQLite 내장). 구성은 두 가지입니다.

방법 A — 라인 PC 에 동봉된 Web 서버 켜기 (설정 마법사)

설치 구성 선택에서 "Web 서버 포함"을 켠 PC 에서는 명령어 없이 화면에서 켤 수 있습니다.

  1. 시스템 설정 마법사(3장)를 실행해 2 단계 Application Settings 로 이동합니다.
  2. "Web 서버 초기 구성 (이 PC)" 카드에서 관리자(admin) 계정 비밀번호를 입력하고 구성 버튼을 누릅니다. 비밀번호는 8 자 이상이어야 하며 12 자 이상을 권장합니다.
  3. 서비스 등록과 시작이 자동으로 진행되고, 카드에 "✔ 초기 구성 완료" 와 서비스 상태(Running)가 표시됩니다.
  4. 같은 페이지의 Web Server URL 이 http://localhost:5292 인지 확인하고 마법사를 끝까지 진행해 저장합니다.
  5. 브라우저에서 http://localhost:5292 에 접속해 로그인 화면이 뜨면 완료입니다. 계정은 admin / 방금 입력한 비밀번호입니다.
  • 구성은 끝났는데 서비스가 멈춰 있으면(Stopped) 카드에 [서비스 시작 (관리자 권한)] 버튼이 나타납니다. 누르면 Windows 권한 확인 창(UAC)이 뜨고, 승인하면 서비스가 부팅 시 자동 시작으로 바뀐 뒤 곧바로 시작됩니다.
  • 이 구성에서는 Web 서버가 이 PC 안에서만(127.0.0.1) 응답합니다. 다른 PC 의 브라우저에서 보려면 §2.5 의 안내에 따라 바인딩 주소와 방화벽을 열어야 합니다.

방법 B — 별도 서버 PC 에 설치 (배포 스크립트)

라인이 여러 대이거나 사무실에서 항상 접속해야 하면 서버 PC 를 따로 둡니다. Web 서버 배포 패키지는 설치 매체에 MSI 와 함께 제공되며(없으면 공급사에 요청), 관리자 PowerShell 에서 다음을 실행합니다.

# 관리자 PowerShell — 압축을 푼 폴더로 이동
cd <압축 푼 폴더>\deploy
.\Install-Web-Offline.ps1

스크립트가 서비스 등록 · 서명 키 생성 · 초기 관리자 비밀번호 생성 · 설정 파일 권한 제한 · 방화벽 규칙까지 한 번에 처리하고, 화면에 초기 admin 비밀번호를 표시합니다. 기본값은 설치 폴더 C:\Deploy\BodaVmsWeb, 데이터 폴더 C:\ProgramData\BODA\VMS, 포트 5292 입니다. 옵션으로 바꿀 수 있습니다.

.\Install-Web-Offline.ps1 -Port 8080 -InstallPath "D:\BODA Web" -DataDir "D:\BODA Data"
서명 키의 유일한 사본은 서버의 appsettings.Production.json 입니다. 이 파일을 잃으면 모든 사용자가 다시 로그인해야 하므로 설치 직후 안전한 곳에 백업하세요. 첫 로그인 후에는 admin 비밀번호를 바꾸고, 필요한 사용자를 가입 → 승인으로 추가합니다(§8.2).

2.4 MLOps 서버 · 학습 워커 설치 (선택)

딥러닝 모델을 웹에서 만들어 라인에 배포하려는 현장만 설치합니다. 검사 자체는 MLOps 없이도 동작합니다.

MLOps 서버

  1. 서버 PC(Web 서버와 같은 PC 여도 됨)에 MLOps 배포 패키지를 풀고 관리자 PowerShell 에서 실행합니다. 
    .\scripts\install-server-service.ps1 -DataDir D:\BODA-MLOps -ProductionWebUrl http://<Web 서버>:5292
  2. 서비스 BodaVmsMlops(포트 5310)가 등록되고 방화벽 규칙이 추가됩니다. 데이터(DB · 사진 · 모델)는 -DataDir 폴더에 저장되므로 이 폴더를 백업 대상에 넣습니다.
  3. MLOps 화면은 Web 서버의 관리자 계정으로 로그인합니다(§9.1). 두 서버가 같은 서명 키를 쓰도록 스크립트가 -JwtKey 를 요구하며, 값은 파일이 아니라 서비스 환경변수에만 저장됩니다.

학습 워커 (GPU PC)

  1. NVIDIA GPU(VRAM 8GB 이상), CUDA 12.4 지원 드라이버(550 이상), Python 3.12 64-bit 를 "모든 사용자용"으로 설치합니다.
  2. MLOps 화면 학습 → 워커 → [워커 등록]에서 이름을 넣고 [발급]을 눌러 wk_… 토큰을 받습니다. 토큰은 이때 한 번만 표시됩니다.
  3. BODA-VMS-TrainWorker-0.1.1.msi 를 실행하고 "워커 연결 설정" 화면에 관리 서버 주소(http://서버:5310) · 워커 토큰 · 워커 이름을 입력합니다.
  4. 설치가 끝나면 서비스 BodaVmsTrainWorker 가 시작되어 첫 실행 시 파이썬 환경(venv, 약 6GB)을 준비합니다. 온라인 설치는 10~40 분이 걸립니다. 폐쇄망은 wheel 번들이 동봉된 -offline.msi 를 씁니다.
  5. MLOps 워커 화면에서 상태가 대기 중으로 바뀌면 준비 완료입니다. 로그는 %ProgramData%\BODA VMS TrainWorker\logs 에 남습니다.

2.5 네트워크 · 방화벽

  • Web 서버를 별도 PC 에 설치하면 배포 스크립트가 방화벽 인바운드 규칙 BODA VMS Web 을 만듭니다. 라인 PC 와 동봉 구성(방법 A)은 기본이 127.0.0.1 바인딩이라 외부 접속이 막혀 있습니다 — 다른 PC 에서 보려면 appsettings.Production.json 의 Kestrel:Endpoints:Http:Url 을 http://0.0.0.0:5292 로 바꾸고 방화벽에서 5292 를 사내망(Private/Domain)에만 엽니다.
  • 카메라는 전용 네트워크 카드에 직결하고, 그 카드에만 카메라와 같은 대역의 고정 IP 를 줍니다.
  • 보안 모드가 Production 인 라인 PC 는 다른 PC 를 가리키는 http:// 서버 주소를 거부합니다(§3.8). 원격 서버는 https:// 로 열거나(사설 인증서), 사내 실증 단계에서는 Development 모드를 씁니다. 같은 PC 를 가리키는 localhost 주소는 http 여도 허용됩니다.

2.6 SW 라이선스 설치 · 활성화

SW 라이선스는 "이 PC 에서 BODA VMS 를 사용해도 된다"는 사용권 파일(license.lic)입니다. 인터넷 연결 없이 파일 하나로 동작하므로 폐쇄망에서도 추가 설정이 필요 없습니다. 지금은 도입 전환기라 라이선스가 없어도 사용 제한은 없으며, 상태 표시와 기록에 "미설치" 경고만 남습니다.

지문 코드로 발급받기

  1. 시스템 설정 마법사 마지막 페이지(Security & License)의 SW 라이선스 카드에서 지문 코드(예: 0X0Y9-MMS36-7540K, 15 자)를 [복사]해 본사 담당자에게 전달합니다. 전화 · 메신저 · 이메일 모두 가능합니다.
  2. 발급받은 license.lic 파일을 USB 등으로 이 PC 에 옮깁니다. 파일은 이 PC 에서만 유효합니다.
  3. [라이선스 파일 가져오기...] 를 누르고 파일을 선택합니다. 권한 확인 창(UAC)이 뜨면 [예]를 누릅니다.
  4. 카드의 현재 상태가 정상으로 바뀌면 완료입니다.

서버 1 대 + 라인 여러 대 구성

Web 서버가 있는 구성이라면 라이선스는 서버 PC 에만 설치합니다. 각 라인 PC 는 서버에서 자동으로 사용권(좌석)을 받아 가며, 라인 PC 를 교체해도 재발급이 필요 없습니다. 좌석 현황은 Web 시스템 관리 → SW 라이선스에서 봅니다(§8.24). 서버가 꺼져 있어도 라인 PC 는 마지막으로 좌석을 받은 시점부터 72 시간 동안 정상 동작합니다.

재발급이 필요한 경우

  • 지문 불일치 — 다른 PC 용 라이선스이거나, 부품 교체 · Windows 재설치로 지문이 바뀐 경우입니다. 새 지문 코드로 재발급을 요청합니다.
  • 만료 임박 · 유지보수 만료 — 계약 갱신 후 받은 새 파일을 같은 방법으로 가져오기 하면 덮어써집니다.

2.7 업그레이드와 제거

인앱 업데이트 (권장)

새 버전이 나오면 VMS 가 시작할 때 "업데이트 가능" 창으로 알려 주고, 사이드 패널 Updates 섹션에 배지가 표시됩니다.

  1. 안내 창에서 [확인]을 누릅니다. 수동으로 확인하려면 사이드 패널 Updates 의 [Check for updates] 를 누릅니다.
  2. 설치 파일이 앱 안에서 다운로드되며 Updates 섹션에 진행률이 표시됩니다. [다운로드 취소]로 멈출 수 있고, 내려받은 파일은 손상 여부(SHA-256)를 자동 검증합니다.
  3. 다운로드가 끝나면 설치 시작 확인 창이 뜹니다. 시작하면 Windows 권한 확인 창(UAC)이 한 번 뜨고, 진행률 창(버전 · 현재 작업 · %)이 표시되는 동안 기다립니다.
  4. 설치가 끝나면 VMS 가 자동으로 다시 실행됩니다. 이 PC 에서 Web 서비스를 운영 중이었다면 업데이트가 서비스를 먼저 내리고, 설치 후 다시 시작해 응답까지 확인합니다.
  • 자동 검사(AUTO RUN)가 도는 동안에는 업데이트를 시작할 수 없습니다. 검사를 멈춘 뒤 진행하세요.
  • 다운로드나 설치가 실패하면 브라우저에서 설치 파일을 직접 내려받는 방법이 안내됩니다. 설치 과정 기록은 C:\ProgramData\BODA\VMS\update-bootstrap.log 에 남습니다.

설치 파일로 직접 업그레이드

새 버전 MSI 를 더블 클릭하면 이전 버전이 자동으로 제거되고 새 버전이 설치됩니다. 설치 구성 선택은 이전 선택이 유지되며, 설정 · 레시피 · 검사 이력 · 캘리브레이션은 그대로 보존됩니다.

제거

  • Windows 설정 → 앱 → "BODA Vision System" → 제거. 또는 시작 메뉴의 제거 바로가기.
  • 사용자 데이터(%LocalAppData%\BODA VISION AI\)와 Web 데이터(C:\ProgramData\BODA\VMS\)는 제거해도 남습니다. 완전히 지우려면 두 폴더를 직접 삭제합니다.
