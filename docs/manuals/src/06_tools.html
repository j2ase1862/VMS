6. 비전 도구 설명 및 사용법

Tool Palette 의 도구를 카테고리 순서대로 설명합니다. 도구마다 용도 · 설정 패널 · 주요 파라미터 · 결과 값 · 사용 요령을 정리했으며, 설정 패널 그림은 Expert Mode 를 끈 기본 상태입니다. 파라미터의 정확한 범위와 전체 목록은 부록 13.2 를, 도구를 연결하는 방법은 §5.5 를 참고하세요. 각 파라미터 옆의 물음표(?)에 마우스를 올리면 같은 설명이 프로그램 안에서도 표시됩니다.

6.1 Preprocessing (Color) — 컬러 전처리

Blur — 블러(흐림)

이미지에 블러를 적용해 노이즈를 줄입니다. 엣지 검출이나 이진화 앞에 두면 작은 잡음이 검출에 섞이는 것을 막을 수 있습니다. 컬러 이미지는 컬러 그대로, 그레이 이미지는 그레이 그대로 나옵니다.

파라미터기본값 / 범위설명
Blur TypeGaussian (Average · Gaussian · Median · Bilateral)블러 종류. Gaussian 이 범용, Median 은 점 노이즈(소금-후추) 제거에, Bilateral 은 엣지를 살리며 평활화할 때 씁니다
Kernel Size5 [1~31, 홀수]커널 크기. 클수록 강하게 흐려집니다
Sigma X / Sigma Y0 [0~10]가우시안 표준편차. 0 이면 커널 크기에서 자동 계산(Y 가 0 이면 X 와 같음)

결과 값 — BlurType · KernelSize · ROI (판정 없음, 항상 성공)

  • Kernel Size 는 3~7 에서 시작해 잡음이 사라질 때까지만 키우세요. 너무 크면 검사 대상의 엣지까지 흐려집니다.
  • Use ROI 를 켜면 ROI 안쪽만 흐리게 하고 바깥은 그대로 둡니다.

Morphology — 형태학 연산

이진화(또는 그레이) 이미지에 침식 · 팽창 등 형태학 연산을 적용합니다. Blob 검출 전에 작은 잡음을 지우거나, 끊어진 영역을 잇거나, 구멍을 메울 때 씁니다.

파라미터기본값 / 범위설명
OperationDilate (Erode · Dilate · Open · Close · Gradient · TopHat · BlackHat)Erode 축소 · 잡음 제거 / Dilate 확대 · 구멍 채움 / Open 침식→팽창(작은 점 제거) / Close 팽창→침식(작은 구멍 메움) / Gradient 윤곽 / TopHat 밝은 작은 영역 / BlackHat 어두운 작은 영역
Kernel Width / Height3 / 3 [1~21]구조 요소 크기. 클수록 효과가 강합니다
Iterations1 [1~10]연산 반복 횟수

결과 값 — Operation · KernelSize · Iterations (판정 없음)

  • 점 모양 잡음을 지우려면 Open, 글자나 마킹의 끊김을 이으려면 Close 를 먼저 시도하세요.
  • Threshold → Morphology → Blob 순서가 기본 구성입니다.

Image Enhance — 선명도 보정

Sharpen 또는 Unsharp Mask 로 이미지 선명도를 높입니다. 흐릿한 마킹이나 작은 글자를 OCR · Code Reader 로 읽기 전에 두면 인식률이 올라갑니다.

파라미터기본값 / 범위설명
ModeUnsharpMask (Sharpen · UnsharpMask)Sharpen 은 3×3 라플라시안(빠르지만 잡음도 함께 강조), UnsharpMask 가 권장
Amount1.0 [0.1~3.0]강조 정도. 0.5~2.0 이 일반적이며 과하면 테두리에 후광(halo)이 생깁니다
Blur Kernel5 [3~31, 홀수]Unsharp Mask 의 블러 커널
Threshold (0=off)0 [0~64]0 이면 모든 픽셀 강화, 5~15 는 잡음 억제와 글자 강화의 균형, 30 이상은 강한 엣지만

결과 값 — Success (판정 없음)

  • 인쇄 글자가 번져 보이는 라벨은 Image Enhance → OCR 로 연결해 보세요.

Polar Unwrap — 극좌표 펼치기

캡 · 약병 · 파이프처럼 둥근 표면에 둘러 인쇄된 라벨을 극좌표 변환으로 직사각형 띠로 펼칩니다. 펼친 이미지를 OCR 이나 Code Reader 에 연결하면 곡면 글자를 읽을 수 있습니다.

파라미터기본값 / 범위설명
Center X / Center Y (px)0 / 0원의 중심. Circle Fit 을 Coordinates 로 연결하면 자동으로 채워집니다
Inner Radius / Outer Radius (px)50 / 200라벨 안쪽 · 바깥쪽 경계 반지름. Circle Fit 연결 시 반지름의 0.6 배 · 1.1 배가 자동 설정됩니다
Start Angle (°)0 [0~360]펼치기 시작 각도. 0 = 오른쪽(3 시), 90 = 위, 180 = 왼쪽, 270 = 아래
DirectionCounterclockwise (Clockwise · Counterclockwise)펼치는 방향
Output Width / Height (0=auto)0 / 0출력 크기. 0 이면 둘레 · 반지름 차이에서 자동

결과 값 — CenterX · CenterY · InnerRadius · OuterRadius · OutputWidth · OutputHeight (판정 없음)

  • 전형 구성: Circle Fit →(Coordinates) Polar Unwrap →(Image) OCR. Circle Fit 이 찾은 중심 · 반지름이 그대로 넘어와 부품이 조금 움직여도 따라갑니다.

6.2 Conversion (Gray) — 그레이 변환

Grayscale — 그레이 변환

컬러 이미지를 흑백(8-bit 그레이)으로 바꿉니다. 대부분의 비전 도구는 그레이에서 더 빠르고 안정적으로 동작하며, Feature Match 는 그레이 입력만 받으므로 컬러 카메라 레시피에서는 맨 앞에 둡니다. 이미 그레이면 그대로 통과합니다.

이 도구는 별도 수치 파라미터 없이 입력 연결과 ROI 만으로 동작합니다.

결과 값 — Width · Height · Channels (판정 없음, 파라미터 없음)

  • 컬러 정보로 검사해야 하는 도구(Color Extract · Color Match)는 이 도구 앞에서 원본 이미지를 연결하세요.

Threshold — 이진화

임계값을 기준으로 이미지를 흰색(255)과 검은색(0)으로 나눕니다. 밝기 차이로 대상과 배경을 분리해 Blob 검출로 넘기는 가장 기본적인 전처리입니다. 출력 마스크는 PointCloud Mask Crop 에 연결해 3D 점군을 자를 때도 씁니다.

파라미터기본값 / 범위설명
Threshold Value128 [0~255] (Web 연동 가능)이 값보다 밝은 픽셀이 흰색이 됩니다
Max Value255 [0~255]흰색으로 칠할 값(보통 255)
Use Otsu해제히스토그램에서 임계값을 자동으로 정합니다. 밝기 분포가 두 봉우리인 이미지에 효과적
Use Adaptive해제국소 영역마다 임계값을 정합니다. 조명이 고르지 않은 이미지에 효과적
Block Size / Constant C11 / 2Adaptive 전용 — 국소 블록 크기(홀수)와 평균에서 뺄 상수

결과 값 — ThresholdValue · WhitePixelCount · WhitePixelRatio (판정 없음)

  • 실행 후 이미지 소스를 Result Image 로 바꾸면 이진화 결과를 바로 볼 수 있습니다. 대상이 하얗게, 배경이 검게 나오도록 값을 맞추세요.
  • 조명이 가장자리에서 어두워지면 Use Adaptive 를 켜 보세요.

Edge Detection — 에지 검출

이미지에서 경계선(에지)만 남깁니다. 윤곽 형상 분석이나 직선 · 원 피팅의 전처리로 씁니다.

파라미터기본값 / 범위설명
MethodCanny (Canny · Sobel · Scharr · Laplacian)Canny 가 가장 범용. Sobel · Scharr 는 방향성 1 차 미분, Laplacian 은 2 차 미분
Canny Threshold 1 / 250 / 150 [0~255]낮은 임계(에지 연결) / 높은 임계(강한 에지 판정)
Aperture Size3 [3~7]Sobel 커널 크기
L2 Gradient해제더 정확한 L2 노름 사용(느림)

결과 값 — EdgePixelCount · EdgePixelRatio (판정 없음)

  • Threshold 2 를 올리면 약한 에지가 사라지고, Threshold 1 을 내리면 끊긴 에지가 이어집니다. 보통 1:2~1:3 비율로 둡니다.

Histogram — 히스토그램 분석 · 평활화

이미지 밝기 분포를 분석하거나 대비를 개선합니다. 조명이 약해 대비가 낮은 이미지에 Equalize · CLAHE 를 적용하면 후속 검출이 안정됩니다. 분석 모드의 평균 · 표준편차는 조명 상태 감시에 쓸 수 있습니다.

파라미터기본값 / 범위설명
OperationAnalyze (Analyze · Equalize · CLAHE)분석만 / 전체 평활화 / 적응형 평활화(국소 대비)
Clip Limit2.0 [1~10]CLAHE 대비 제한. 클수록 대비가 강해집니다
Tile Grid Width / Height8 / 8 [1~16]CLAHE 타일 격자 분할 수

결과 값 — MinValue · MaxValue · MeanValue · StdDev (판정 없음)

  • MeanValue 를 PLC 에 매핑하면 조명이 어두워지는 추세를 PLC 에서 감시할 수 있습니다.

6.3 Pattern Matching — 패턴 매칭

Feature Match — 특징(에지) 기반 패턴 매칭

제품의 윤곽(에지)을 학습해 두었다가 검사 이미지에서 같은 패턴의 위치 · 각도 · 크기를 찾습니다. 부품 유무 확인, 위치 검출, 뒤 도구의 ROI 를 따라가게 하는 기준(Fixture), 얼라인의 기준으로 가장 많이 쓰는 도구입니다. 8-bit 그레이 이미지만 받으므로 컬러 카메라에서는 앞에 Grayscale 을 둡니다.

파라미터기본값 / 범위설명
Models · [Add Model] [Train Selected] [Delete Model]—학습 모델 목록. 학습 영역(ROI)을 그린 뒤 [Train Selected] 로 학습합니다. 오른쪽에 학습된 특징 이미지가 표시됩니다
재학습 원점UseCurrentImage (UseCurrentImage · KeepReference)재학습 시 원점(패턴 중심 · 각도)을 현재 ROI 로 옮길지(기본), 기준 이미지 · 원점을 유지하고 특징만 갱신할지(얼라인 마스터 유지)
Score Threshold0.50 [0.1~1]이 점수 이상이면 검출. 0.5 느슨 · 0.7 일반 · 0.85 엄격

Min Coverage0 [0~1]특징점 일치 비율 하한. 반쪽만 맞은 매칭(중심이 어긋남)을 걸러냅니다. 0.6~0.75 권장, 0 = 끔
Contrast Invariant / Auto Apply Tune해제 / 켬명암 반전에도 매칭 / 특징점 수 · 피라미드 레벨을 자동 설정
Use Training Region · [Show ROI] [Draw ROI] [Clear]—학습 영역. 제품이 기울어 놓였으면 RectAffine(회전 사각형)으로 그리면 그 각도가 기준 각도가 됩니다

[안정 특징 정제 (샘플 이미지)...]—현장 이미지 2 장 이상을 골라 흔들리는 에지를 자동으로 마스크에 추가하고 재학습

  • 학습 절차 — ① 기준 부품 이미지를 열고 ② [Draw ROI] 로 제품 윤곽을 감싸는 학습 영역을 그린 뒤 ③ [Train Selected]. 특징 이미지의 초록 점이 제품 윤곽을 따라 촘촘해야 정상이며 60 개 미만이면 상태바에 경고가 뜹니다(Canny 임계를 낮추거나 영역을 넓히세요).
  • 그림자 · 반사가 함께 학습되면 중심 좌표가 끌려갑니다 — [Edit Mask...] 로 제외하거나 [안정 특징 정제] 를 쓰세요. 마스크 편집기에서 초록 = 남는 에지, 주황 = 제외되는 에지입니다.
  • 반쪽 매칭으로 중심이 어긋나면 Min Coverage 를 0.6~0.75 로 켜세요. 기각 사유가 결과 메시지에 표시됩니다.
  • 이 도구를 Coordinates 로 뒤 도구에 연결하면 뒤 도구의 ROI 가 위치와 각도를 모두 따라갑니다. 단, 이 도구 자신의 Search Region 은 Fixture 로 옮겨지지 않습니다.
얼라인 기준 — Match Align 은 이 도구의 학습 위치 · 학습 ROI 각도를 기준 포즈로 씁니다. 부품을 옮겨 놓고 재학습하면 기준도 새 위치로 바뀌므로, 마스터 포즈를 유지하려면 재학습 원점을 KeepReference 로 두세요.

6.4 Alignment — 얼라인

Match Align — 2D 얼라인 (ΔX / ΔY / Δθ)

Feature Match 가 찾은 현재 포즈(중심 · 각도)를 기준(마스터) 포즈와 비교해 변위 ΔX · ΔY · Δθ 를 계산합니다. 캘리브레이션(또는 스텝 Resolution)이 있으면 mm 로도 내고, 핸드아이 행렬로 로봇 · 스테이지 좌표 변위(RobotDX · RobotDY · RobotDTheta)까지 만들어 PLC 로 보낼 수 있습니다. 카메라 1 대로 부품을 보는 표준 2D 얼라인 구성입니다.

6.14 Calibration — 보정

Image Rectify — 렌즈 왜곡 · 기울기 보정

캘리브레이션(§5.9) 결과로 이미지의 렌즈 왜곡을 펴고(Undistort), N-Point 방식이면 기울어진 평면을 정면으로 펴서(Apply Homography) 뒤따르는 측정 도구가 왜곡 없는 이미지를 보게 합니다. 측정 파이프라인 맨 앞에 둡니다.

파라미터기본값 / 범위설명
Undistort (lens distortion)켬렌즈 왜곡 보정 — Checkerboard · Circles Grid 캘리브레이션 결과로만 동작
Apply Homography (NPoint planar)해제기울어진 평면 펴기 — N-Point 캘리브레이션 결과로만 동작

결과 값 — DidUndistort · DidHomography · PixelSizeMm

판정 — 판정 없음. 캘리브레이션이 레시피에 없으면 이미지를 그대로 통과시킵니다(오류 아님).

  • 켰는데 화면이 그대로면 캘리브레이션 방식이 맞지 않는 경우입니다 — 상태 메시지에 실제로 무엇이 적용됐는지 표시됩니다.
  • 펴는 과정에서 가장자리가 잘리거나 늘어날 수 있으므로 뒤 도구의 ROI 는 편 뒤의 화면 기준으로 잡으세요.

6.15 Surface Analysis — 표면 분석

Photometric Stereo — 조명 방향별 사진 합성 (표면 요철 강조)

같은 자리에서 조명 방향만 바꿔 찍은 사진 3 장 이상(보통 4 장)을 합쳐 눌린 자국 · 얕은 긁힘 · 각인 누락처럼 밝기 차이로는 안 보이는 표면 요철을 드러냅니다. 결함 강조 이미지(DefectEnhanced)를 Blob · Threshold 로 넘겨 판정합니다.

파라미터기본값 / 범위설명
Output Type · Curvature GainDefectEnhanced (NormalMap · Albedo · DefectEnhanced) · 8 [1~30]결함 검사용은 DefectEnhanced. Gain 을 올리면 얕은 결함이 드러나지만 표면 거칠기도 도드라짐. NormalMap 은 확인용, Albedo 는 인쇄 · 오염 검사용
Shadow Threshold · Highlight Threshold10 [0~100] · 245 [155~255]이보다 어두운 픽셀(그림자) · 밝은 픽셀(정반사 포화)은 계산 신뢰도를 낮춥니다. 광택 금속면은 Highlight 를 조금 낮춥니다
Light Sources (≥3) · [+ Add Light]—조명마다 방향 벡터(Lx · Ly · Lz)와 그 조명에서 찍은 이미지 경로를 등록합니다. 방향이 실제 배치와 다르면 결과가 통째로 어긋납니다

결과 값 — LightCount · OutputType (출력은 합성 이미지)

판정 — 자체 판정 없음 — DefectEnhanced → Blob 또는 Threshold → Result 로 판정합니다.

  • 조명 4 개를 제품 둘레에 배치하고 하나씩 켜 가며 같은 장면을 찍는 구성이 표준입니다.
