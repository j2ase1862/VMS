3. 시스템 설정 마법사 (VMS.AppSetup)

⚙ 이 장은 설치 담당자 · 관리자용입니다. 시스템 설정 마법사는 카메라 · PLC · 로봇 · IO 보드 · 서버 연동 · 보안 · 라이선스 등 시스템 전체 구성을 저장하는 프로그램입니다. 일반 작업자는 사용할 일이 없습니다.

3.1 실행 방법과 저장 동작

시스템 설정 마법사는 다음 세 가지 경로로 실행합니다.

  • 최초 실행 자동 — VMS 를 설치 후 처음 실행하면(설정 파일이 없으면) 안내 창과 함께 마법사가 자동으로 열립니다. 저장을 마친 뒤 VMS 를 다시 실행하세요.
  • VMS 에서 실행 — 사이드 패널 External Tools 의 [System Setup] 버튼 (Supervisor · Admin 전용, §4.6).
  • 시작 메뉴 — "BODA Vision System" 그룹의 설정 마법사 바로가기. 한 PC 에서 두 라인을 운용할 때는 VMS.AppSetup.exe --instance 이름 으로 실행합니다(§11.5).

마법사는 총 7 단계이며, 각 단계 하단의 [← Back] / [Next] 로 이동하고 마지막 단계에서 [Finish] 를 누르면 설정 파일(%LocalAppData%\BODA VISION AI\system_config.json)에 저장됩니다. 저장한 설정은 VMS 를 다시 시작할 때 반영됩니다 — 운전 중이라면 검사를 멈추고 VMS 를 재시작하세요. [Finish] 를 누르지 않고 닫으면 아무것도 바뀌지 않습니다.

입력란 라벨 옆의 파란 물음표(?) 아이콘에 마우스를 올리면 그 항목의 설명이 말풍선으로 표시됩니다. 이 장의 표와 같은 내용입니다.

3.9 저장 후 확인할 것

  1. VMS 를 실행해 하단 상태바를 봅니다 — CAM n/m 이 초록(전부 연결), Web Connected(또는 단독 모드) 인지 확인합니다(§4.7).
  2. PLC 를 구성했다면 PLC 칩이 초록인지, IO 보드를 구성했다면 IO n/m 칩이 초록인지 확인합니다. 빨간색이면 System Log 의 사유를 보고 12장을 참고합니다.
  3. Web 연동 현장은 Web 의 설비 관리 → 비전 클라이언트 화면에 이 라인이 온라인으로 보이는지 확인합니다(§8.16).
