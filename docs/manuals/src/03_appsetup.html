3. 시스템 설정 마법사 (VMS.AppSetup)

⚙ 이 장은 설치 담당자 · 관리자용입니다. 시스템 설정 마법사는 카메라 · IO 보드 · 서버 연동 · 보안 · 라이선스 등 시스템 전체 구성을 저장하는 프로그램입니다. 일반 작업자는 사용할 일이 없습니다.

3.1 실행 방법과 저장 동작

시스템 설정 마법사는 다음 세 가지 경로로 실행합니다.

  • 최초 실행 자동 — VMS 를 설치 후 처음 실행하면(설정 파일이 없거나 마법사를 마치지 않았으면) 안내 창과 함께 마법사가 자동으로 열립니다. 저장을 마친 뒤 VMS 를 다시 실행하세요.
  • VMS 에서 실행 — 사이드 패널 External Tools 의 [System Setup] 버튼 (Supervisor · Admin 전용, §4.6).
  • 시작 메뉴 — VASIM 폴더의 BODA VMS 설정 마법사 (AppSetup) 바로가기. 한 PC 에서 두 라인을 운용할 때는 VMS.AppSetup.exe --instance 이름 으로 실행합니다(§9.5).

마법사 창의 제목은 BODA VMS Setup 이며, 오른쪽 위에 현재 단계(예: Step 2 of 5)가 표시됩니다. 기본 구성 라이선스가 설치된 PC 에서 마법사는 총 5 단계이며, 각 단계 하단의 [← Back] / [Next] 로 이동하고 마지막 단계에서 [Finish] 를 누르면 설정 파일(%LocalAppData%\BODA VISION AI\system_config.json)에 저장되고 "Setup Complete" 창이 뜬 뒤 마법사가 닫힙니다. 저장한 설정은 VMS 를 다시 시작할 때 반영됩니다 — 운전 중이라면 검사를 멈추고 VMS 를 재시작하세요. [Finish] 를 누르지 않고 닫으면 설정 파일과 관리자 비밀번호는 바뀌지 않습니다. 단, 2 단계의 [초기 구성 실행 (관리자 권한)] · [서비스 시작 (관리자 권한)] 과 마지막 단계의 [라이선스 파일 가져오기...] 는 누르는 즉시 적용되어, [Finish] 없이 닫아도 그대로 남습니다.

라이선스를 먼저 설치하세요. 이 PC 에 라이선스 파일이 없으면(설치 직후, 또는 서버에서 사용권을 받아 쓰는 라인 PC) 마법사가 7 단계(Step N of 7)로 표시되고, 3 단계 다음에 PLC Communication · Robot Configuration 단계가, 카메라 종류 · 제조사 목록과 고급 설정에 확장 옵션 항목이 더 보입니다. IO 보드는 6 단계, Security & License 는 7 단계가 됩니다. 마지막 단계에서 기본 구성 라이선스를 가져오면(§2.5) 그 자리에서 5 단계로 바뀌므로, 처음 설치할 때는 마지막 단계에서 라이선스를 먼저 가져온 뒤 [← Back] 으로 돌아가 2 단계부터 설정하는 순서를 권장합니다. 이 장의 단계 번호와 화면은 기본 구성 라이선스가 설치된 5 단계 기준입니다. 라이선스 없이 진행할 때는 이 장에 없는 단계의 값을 바꾸지 않고 [Next] 로 넘어갑니다.

입력란 라벨 옆의 파란 물음표(?) 아이콘에 마우스를 올리면 그 항목의 설명이 말풍선으로 표시됩니다. 이 장의 표와 같은 항목을 설명합니다.

3.7 저장 후 확인할 것

  1. VMS 를 실행해 하단 상태바를 봅니다 — CAM n/m 이 초록(전부 연결), Web Connected(또는 단독 모드) 인지 확인합니다(§4.7).
  2. IO 보드를 구성했다면 IO n/m 칩이 초록인지 확인합니다. 빨간색이면 System Log 의 사유를 보고 10장을 참고합니다.
  3. Web 연동 현장은 Web 의 설비 관리 → 비전 클라이언트 화면에 이 라인이 온라인으로 보이는지 확인합니다(§8.16).
