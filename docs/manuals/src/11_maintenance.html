11. 유지보수

⚙ 이 장은 관리자 · 설치 담당자용입니다. 백업, 데이터 보존, 카메라 교체, 라이선스 재발급, 다중 인스턴스 운용을 다룹니다.

11.1 백업과 복원

라인 PC (VMS)

  • 수동 백업 — Admin Tools → Backup / Restore → [Run Backup...] 로 ZIP 을 만듭니다(§4.11). 설정 파일 · 레이아웃 · PLC 신호 맵 · 사용자 DB · 검사 이력 DB · 레시피 전체가 들어가며 감사 로그는 선택입니다. 레시피를 크게 바꾸기 전, 프로그램을 업그레이드하기 전, PC 를 교체하기 전에 받아 두세요.
  • 자동 백업 — Admin Tools → Auto Backup Settings 에서 활성화 · 주기(시간) · 보존(일) · 위치를 정합니다. 기본 위치는 %LocalAppData%\BODA VISION AI\backups 이며 다른 드라이브나 네트워크 폴더를 권장합니다.
  • 복원 — Backup / Restore 의 백업 복원에서 파일을 고르고 [기존 파일 덮어쓰기] 를 켠 뒤 [Run Restore]. 복원 후 VMS 를 재시작합니다. 다른 PC 에 복원하면 카메라 구성이 다를 수 있으므로 설정 마법사 3 단계를 확인하세요.

Web 서버

  • 서버는 하루 한 번 자동으로 DB 사본(boda-vision-YYYYMMDD-HHmmss.db)을 C:\ProgramData\BODA\VMS\backups\ 에 만들고 14 벌을 보관합니다. 운영 중에도 멈추지 않습니다. 마지막 백업 시각을 기준으로 다음 시점을 잡으므로 재시작이 잦아도 밀리지 않습니다.
  • 백업 폴더를 다른 드라이브로 바꾸려면 appsettings.Production.json 의 DatabaseBackup:Destination 에 절대 경로를 넣습니다.
  • 수동 사본이 필요하면 서비스를 멈추고 BodaVision.db · BodaVision.db-wal · BodaVision.db-shm 세 파일을 함께 복사합니다. 검사 사진은 C:\ProgramData\BODA\VMS\images\ 에 있습니다.
  • 서명 키가 든 appsettings.Production.json 도 함께 백업합니다(§2.3).

MLOps 서버 · 워커

MLOps 데이터 폴더(D:\BODA-MLOps 등 설치 시 지정한 -DataDir)에 DB · 사진 · 모델이 모두 있습니다. 이 폴더를 백업하면 됩니다. 워커의 파이썬 환경(%ProgramData%\BODA VMS TrainWorker)은 재설치로 복구되므로 백업하지 않아도 됩니다.

11.3 카메라 교체 · IP 변경

  1. 새 카메라를 같은 네트워크 카드에 연결하고, 제조사 프로그램(pylon Viewer · MVS · Mech-Eye Viewer)으로 카메라에 기존과 같은 고정 IP 를 부여합니다. IP 가 같으면 VMS 설정을 바꿀 필요가 없습니다.
  2. IP 나 제조사가 바뀌면 시스템 설정 마법사 3 단계에서 해당 카메라 카드의 IP · 제조사 · 타입을 고치고 [Finish] 로 저장한 뒤 VMS 를 재시작합니다(§3.4). 카메라 순서(카드 순서)가 바뀌면 레시피 스텝 이름("1-1")의 번호도 바뀌므로 순서는 유지하세요.
  3. VMS 를 실행해 상태바 CAM 이 초록인지, 카메라 톱니바퀴 → [Grab] 으로 영상이 들어오는지 확인합니다. 노출 · 게인은 "카메라 설정 유지" 가 켜져 있으면 카메라에 저장된 값을 쓰므로 제조사 프로그램에서 이전 값과 같게 맞춥니다.
  4. 렌즈 · 설치 높이가 바뀌었다면 측정값이 조용히 틀어지므로 캘리브레이션을 다시 하고(§5.9) 대표 부품으로 판정을 재확인합니다.
  5. 다른 PC 에서 만든 레시피를 열 때 이 PC 에 없는 카메라를 쓰면 카메라 재연결 창이 떠서 스텝별로 이 PC 의 카메라를 짝지을 수 있습니다(§5.3).

11.4 라이선스 · 좌석 관리

  • 라이선스 상태는 설정 마법사 7 단계 카드, VMS Health Check 의 License 항목, Web 시스템 관리 → SW 라이선스에서 봅니다.
  • PC 교체 · Windows 재설치 후 "지문 불일치" 가 뜨면 새 지문 코드로 재발급을 요청합니다(§2.6). 서버-라인 구성에서는 서버 PC 만 해당합니다.
  • 라인 PC 를 철거하면 그 좌석은 72 시간 후 자동으로 반환됩니다. 계약 좌석이 모자라면 Web 화면에 경고 배너가 뜹니다.

11.5 한 PC 에서 두 라인 운용 (다중 인스턴스)

PC 한 대에 카메라가 여러 대 있으면 VMS 를 두 개 띄워 각각 다른 라인으로 운용할 수 있습니다.

  1. 바탕화면에 VMS 바로가기를 하나 더 만들고 대상 끝에 --instance line2 를 붙입니다(영문 · 숫자 · 하이픈 · 밑줄 1~32 자).
  2. 설정 마법사도 같은 이름으로 실행합니다: VMS.AppSetup.exe --instance line2. 2 번 라인이 쓸 카메라와 라인 번호를 등록하고 저장합니다. 같은 카메라를 두 인스턴스에 겹쳐 등록하면 안 됩니다 — 카메라는 한 번에 한 프로그램만 연결할 수 있습니다.
  3. 두 바로가기로 VMS 를 각각 실행합니다. 인스턴스마다 설정 · 레시피 · 계정 · 검사 이력이 %LocalAppData%\BODA VISION AI\instances\line2\ 아래에 완전히 분리되어 보관되며, VMS 에서 실행한 VisionSetup · AppSetup 도 같은 인스턴스를 자동으로 씁니다.

11.7 문제 보고 방법

  1. VMS Admin Tools → Support Package... 로 진단 ZIP 을 만듭니다(설정 · 감사 로그 · 환경 정보 · 헬스 스냅샷 · MLOps 전송 큐 상태 포함, 레시피 · 사용자 DB 는 미포함).
  2. 증상이 난 시각과 System Log 의 관련 줄, 화면 캡처를 함께 준비합니다.
  3. Web 문제는 {설치 폴더}\Logs\ 의 해당 날짜 로그와 /health 응답을, MLOps 문제는 학습 작업 상세의 로그를 첨부합니다.
