10. 딥러닝 모델 준비

딥러닝 검사 도구(§6 — Detection · Classify · Anomaly · RF-DETR-seg · OCR)는 학습된 모델 파일(ONNX)로 동작합니다. 모델의 라벨링 · 학습 · 등록은 AI 학습 플랫폼 BODA VMS MLOps(9장)에서 합니다. VMS 와 VisionSetup 은 만들어진 모델을 불러와 검사에 씁니다.

  1. 학습 — MLOps 에서 데이터셋을 라벨링하고 학습 작업을 실행합니다(§9.5 · §9.6). 끝난 모델은 모델 레지스트리에 후보 버전으로 등록됩니다.
  2. 승격 — 모델 레지스트리에서 결과를 확인하고 스테이징 · 운영 단계로 올립니다(§9.9).
  3. 레시피에 지정 — VisionSetup 딥러닝 도구의 Model Path 옆 [레지스트리…] 로 모델을 고르면 model:// 참조가 들어갑니다(§9.10). 라인 PC 는 그 참조가 가리키는 버전을 자동으로 내려받아 씁니다. 모델 파일을 직접 받아 둔 경우에는 Model Path 에 .onnx 경로를 지정해도 됩니다.

10.1 OCR 합성 데이터로 학습하기

날짜 · 로트 번호처럼 형식이 정해진 문자열은 VisionSetup 의 OCR Synth Data(§5)로 학습 데이터를 만들어 MLOps 에서 학습할 수 있습니다.

  1. OCR Synth Data 에서 출력 형식을 PaddleOCR rec 로 두고 [Generate] 로 데이터를 만듭니다.
  2. 출력 폴더 안의 train_crops · val_crops 폴더와 train_rec.txt · val_rec.txt · dict.txt 를 모두 골라 압축합니다. 폴더째 압축하면 업로드가 거절됩니다.
  3. MLOps 의 [데이터셋 버전] ▸ [버전 업로드] 에서 작업 유형 OCR, 형식 ppocr 로 올리고(§9.7) 학습 작업을 실행합니다.
