# 확장 옵션 · 인증 범위 밖 설명 (제출 매뉴얼에서 뺀 조각)

GS 인증 제출 매뉴얼(`docs/manuals/src` → `VMS_사용자매뉴얼_v3.1`)은 **기본 구성**만 설명한다
(TTA 2026-09-30: 인증 범위에서 제외한 기능은 프로그램과 제출 매뉴얼에서도 보이지 않게).
아래 조각은 `build_manual.py` 가 읽지 않는 폴더로 옮겨 둔 것이다 — 제출본에 들어가지 않는다.

| 파일 | 원래 위치 | 내용 |
|---|---|---|
| `mlops.html` | 9장 | AI 학습 플랫폼 (BODA.VMS.MLOps) |
| `deeplearning.html` | 10장 | 딥러닝 모델 준비 (OCR 합성 데이터 학습) |
| `plc.html` | 3.5 · 5.6 · 4.6 (v3.0 번호) | PLC 통신 설정 단계 · 도구 PLC Output · Roller Inspection (2026-11-02, TTA 11월 요청으로 PLC 연동 · 라인스캔 제외) |

조각 안의 장 · 절 번호 읽는 법:
- `mlops.html`(9장) · `deeplearning.html`(10장)의 장 번호와 그 안의 `§9.x` 는 **별책 자체 번호**다. 제출본(본책) 9장 유지보수 · 10장 문제점 및 조치 방법과는 다른 장이다.
- 본책을 가리킬 때는 "본책 §N.N" 으로 적었고, 번호는 지금 본책(1 ~ 11장) 기준이다.
- `plc.html` 의 제목 번호(3.5 4 단계)는 v3.0 번호 그대로다. 지금 본책 3.5 는 IO Board Configuration 이다.
- MLOps 서버 · 학습 워커 설치는 본책에 없다 — MLOps 리포의 설치 가이드를 본다.

로봇 연동 · 핸드아이 · 멀티뷰 · 3D 카메라 실촬영 · MLOps 연동 설정처럼 여러 장에 흩어져 있던 문단은
2026-10-30 정리 커밋에서 지웠다 — 확장 옵션 설명서를 만들 때 그 커밋의 삭제분(`git show`)을 출발점으로 쓴다.
확장 옵션 자체는 `docs/design/license-spec.md` §3a.
